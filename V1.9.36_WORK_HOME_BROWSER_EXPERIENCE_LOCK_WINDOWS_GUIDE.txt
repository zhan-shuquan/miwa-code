V1.9.36｜工作之家统一Work Item Browser体验收口｜Windows更新指南

【基线】
V1.9.35 WORK HOME UNIFIED BROWSER + CONTRIBUTIONS CANDIDATE

【更新方式】
1. 关闭正在运行的AIONE前端/Backend终端。
2. 将本ZIP内 code 文件夹中的内容“合并覆盖”到：
   D:\miwa\code\
   不要删除原目录后重建。
3. 本版新增数据库迁移：data-code\migrations\0060_object_reactions.sql
4. 在Backend目录执行数据库迁移：
   cd /d D:\miwa\code\apps\systems\aione\backend
   npm run db:migrate
5. 迁移完成后重新启动AIONE Backend。
6. 浏览器强制刷新（Ctrl+F5）。

【为什么本版必须迁移+重启Backend】
- 关注接口仍由Backend真实写入。
- 本版新增点赞Backend与object_reactions表。
- /api/v1/work-home现在同时返回点赞状态/数量、金额摘要、已记录工作会话时间。
- /api/v1/work-home/capabilities 应返回 workHomeVersion=V1.9.36。

【人工验收顺序】
A. 卡片体验
- 今日工作切换卡片。
- 列数只应看到：2列 / 3列 / 4列。
- 默认3列；Main变窄后自动降列，不能再出现6列窄卡。

B. 工具栏
- 刷新按钮与卡片/列表/列数在同一右侧工具组。
- 不应出现刷新按钮单独掉到下一行。

C. 全部工作时间筛选
- 全部时间 / 今日 / 本周 / 本月 / 本年 / 自定义。
- 自定义后展开日期输入。
- 更多筛选存在团队/项目/金额等条件。
- 设置条件后“更多筛选”显示数量。
- 点击“重置”恢复当前入口默认条件。

D. 工作记录
- 本周 / 本月 / 本年。
- 人员汇总：人员卡片/列表。
- 工作明细：与全部工作相同的搜索/筛选/排序/卡片列表/2·3·4列组件。

E. 点赞
- 找一项工作点击👍。
- 刷新页面后点赞状态和数量保持。
- 再次点击取消。
- 我的关注 → 点赞记录可以看到本人点赞过的工作。

F. 关注
- 点击☆关注。
- 刷新保持★已关注。
- 我的关注出现该工作。
- 取消关注成功。
- 关注不应把自己变成负责人，也不应扩大执行权限。

G. 钱与时间
- 若某工作存在money_events，应在卡片/列表看到财务摘要。
- 若某工作存在work_sessions，应看到“已记录X分钟/小时”。
- 没有真实数据时不显示示例金额或示例效率数字。
