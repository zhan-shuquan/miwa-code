## A. AIONE隐私补充说明（拟发布正文）

### 1. 适用范围与运营方

美和AIONE一体化工作平台（简称“AIONE”）由美和商会株式会社运营，供经授权的员工及业务协作人员使用。本说明补充公司《個人情報保護方針》，说明AIONE及其商品资料同步工具处理信息的方式；不替代依法适用的劳动、人事或其他合同约定。

运营方联系邮箱：info@miwa-happyhouse.com；地址：〒116-0014 東京都荒川区東日暮里6丁目39番13号 1F；电话：03-6458-3780。

### 2. 信息及目的

平台为登录验证、人员关联、业务权限控制及安全审计，处理Google登录返回的账号标识、邮箱和适用的基本资料，以及ERP提供的员工编号、会员号、姓名、头像、公司、部门、职位、员工状态和业务权限等必要信息。Google密码不由AIONE收集。

平台为选品、建档、文件协作和可追溯业务操作，处理用户填写或上传的商品资料、图片、SKU、采购链接、业务备注、负责人、状态、修改记录及同步结果。用户应避免在商品资料中放入无关的身份证件、银行资料或其他敏感个人信息。

### 3. Google登录与Drive分别授权

Google登录用于验证身份；能否使用业务功能仍由ERP员工资料及后台权限决定。登录不自动授予管理员权限，也不意味着读取用户全部Google服务。

管理员另行授权的“MIWA Product Backup rclone”桌面工具用于商品资料副本。当前Google同意页面请求Drive范围授权，其技术授权范围大于单一商品目录；程序配置将正常复制操作限定到指定商品目录及其版本保留位置。该程序按本地到Drive方向复制，不从Drive反向覆盖商品目录，不执行云端删除镜像。授权可以在Google账号中撤销；撤销将停止后续访问，不自动删除既存业务文件或备份。

### 4. 存储、协作与服务商

ERP是正式业务主数据源，AIONE是员工操作入口。本地商品目录是文件执行基准；WPS用于授权目录内的双向协作；Google Drive用于单向副本。公司可能委托Google、WPS及实际部署服务商处理身份认证、应用托管、文件存储等必要事项。访问限定于经授权人员及服务，不能将业务目录默认公开。

相关服务可能在日本、中国或服务商实际提供服务的其他地区处理数据。具体处理地区、委托关系及适用的跨境要求由公司核实并向相关人员作出必要说明，不以本说明替代依法需要的程序。

### 5. Google用户数据用途限制（待公司确认并落实的承诺）

从Google API取得的数据仅用于已告知、已授权的用户功能及其必要安全维护，不出售，不用于广告定向，不用于训练通用AI模型。人员访问仅限支持、维护、安全或依法必须的必要场景，并采用适当授权和审计。平台对Google API信息的使用和向其他应用的传输遵守Google API Services User Data Policy及其适用的Limited Use要求。

自动识别不等于授权付费生图或公开发布。任何新增数据用途或向新的AI服务传输业务资料，应事先说明并取得所需授权。

### 6. 保存、撤销与删除请求

公司按业务、审计、法律义务及争议处理需要保存必要数据，并定期审查。员工停用后撤销业务访问，但不因此删除应保留的历史业务责任及审计记录。备份可能在正常保留周期内继续存在，限制使用并按既定周期处置。

用户可联系上述邮箱申请查询、更正、删除或限制处理。公司核实身份后依法处理；如因法律或必要业务记录保留不能立即删除，将说明原因。撤销Google授权与业务数据删除是不同操作。

### 7. 安全与更新

采用身份认证、后台权限、受限凭证、访问审计及备份等措施保护数据。安全事件按实际情况和适用要求处理。重大用途或共享方式变更将在实施前予以说明，并取得依法或服务政策要求的同意。

1. **适用对象**：本平台供公司授权的员工和协作人员办理业务，不构成面向公众的自由注册服务。本条款不变更劳动合同或已生效业务合同。
2. **账号与权限**：使用本人经ERP登记的Google账号，不出借或冒用身份。管理员按职责分配权限，人员停用或权限变更后相应调整访问；发现异常立即报告。
3. **真实资料**：录入真实且有权使用的商品、规格、图片及参考资料；不得虚构价格、重量、SKU或授权。系统默认值、识别结果及试算参数须由业务人员核实。人工确认不免除公司自身应承担的管理责任。
4. **业务操作**：保存草稿、确认选品、ERP建档、自动美工和上架具有不同含义，以实际状态和授权为准。确认选品不代表允许付费生成图片或公开发布商品。用户不得绕过后台校验、改号规则或权限。
5. **资料及知识产权**：尊重公司、供应商及其他权利人的合法权利。业务资料权益依法律和既有合同处理；本条款不通过上传行为无条件转让第三方知识产权。禁止将业务秘密或个人资料未经授权公开分享。
6. **文件同步**：ERP生成的业务资料仍须经既有校验流程更新正式数据。云端编辑可能异步回传；重要操作以系统保存及处理结果为准。遇到冲突应保留版本并联系管理员，不凭旧副本覆盖正式数据。
7. **服务与费用**：当前员工业务使用不因本条款产生个人付费义务。采购、付费AI或其他付费动作须按公司既定授权办理，不因拥有登录权限而自动获准。
8. **维护与异常**：平台可能因维护、网络或第三方服务故障暂时不可用。公司采取合理措施恢复服务和保护资料；不得据此免除依法不能免除的责任。用户发现保存失败应保留资料并报告，不反复创建重复商品。
9. **限制与终止**：对未经授权、危害安全或违反业务规定的操作，公司可按实际情况限制访问并保留必要记录；对停用、离职或合作终止人员依法依约处理。身份或权限争议可通过管理员及联系邮箱提出。
10. **更新与争议**：重大修改应通知使用者；依法需要确认时另行取得确认。争议先通过公司既有处理机制协商，适用法律及管辖遵循依法适用的强制规定和有效合同，不在本草案中擅自指定排他法院。
