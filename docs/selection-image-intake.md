# 商品图片统一录入修复

四种入口使用既有 `/records/:id/assets` 和 `selection_workspace_assets`，原图、预览图、市场附件分离及ERP关联机制不变。

正式代理对路径中的 `%3A` 解码，而分片上传凭证原先逐字比较路径，导致同一选品记录被误判为过期或无权限。现在按路径段规范化比较，保留所有者、目标、有效期、大小及哈希校验。编码斜杠及路径穿越不能改变目标。前端仅对明确的上传凭证404失效拒绝重建一次传输；不重放网络错误、401、403或业务提交失败。

图片网址使用既有安全下载服务，支持HTTP/HTTPS默认端口，不发送员工凭证。DNS地址检查及固定解析结果，逐跳检查重定向，拒绝内网、链路本地、云元数据、保留地址、用户信息和非HTTP协议。下载设置时间和大小限制。读取后仍走同一图片解码、权限、存储、去重与附件关联流程，外链不是正式图片存储。

仅图片区增加可折叠网址输入，保留正方形展示与既有操作。网址和文件使用相同串行上传队列，失败不会重置表单。

验收：`test-upload-transport.mjs` 验证20MiB分片、编码路径、完整性与所有者隔离；`test-image-intake.mjs` 验证普通员工4.3MB原图、正式代理路径行为、凭证重新获取、原图字节保留、恶意网址拒绝及失败后资料保留。正式浏览器验收结果另附发布记录，不以接口测试替代。
