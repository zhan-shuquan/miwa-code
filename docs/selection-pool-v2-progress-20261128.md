# 选品池V2.0实施与验收记录

稳定基线仍为 `58e0385986d1f0f6f643d2559bd611bfa1a9bb6d` / `aione-stable-20261128`。本轮分支：`feat/selection-pool-v2-20261128`。工作区已有的Google身份认证改动与临时启动脚本不属于本轮，不纳入本轮提交或部署包。

## 已实现，尚待正式环境验收

- 快速收集左右布局，统一图片入口，隐藏单独识别预检；多图时才显示合并选项，SNS核对选项收纳到更多设置。
- 卡片4/6/8列、默认6列，按员工记忆布局；手机单列；紧凑无图占位；卡片与列表显示业务阶段、负责人及下一步。保留原有筛选、分配、退回、归档、导出，并接入批量认领。
- 原始表格超链接、嵌入图片、商品ID、价格读取；明确1688平台和商品ID可补采购链接。非单一金额保留原文并提示，不编造价格。已有表格资料优先，缺失部分才使用现有商品读取能力。
- 链接加截图时提取来源；多链接歧义时保留原文并提示。新增小红书、抖音的确定性来源识别。
- 原始来源、原始选品人、编号保持；新增原始参考图片关联，市场截图与采购主图区分。原始参考图不被后续图片排序删除。
- 复用现有业务事实推导阶段，复用work_items衔接当前待办；同步owner与responsible字段。ERP成功后仅产生一条未指定负责人的后续美工待分配工作，不创建美工执行任务、不调用模型或发布接口。
- 复用work_evidence记录实际操作人、商品、任务、结果、日本业务日期与完成时间。普通保存不计成果；重复点击、重试不重复计成果；系统ERP结果不归给管理员。ERP同一任务失败后成功更新同一结果事实。
- 准备ERP `MIWA Selection Channel` 主数据初始化及现有连接器快照扩展，AIONE只读显示20个入口、四个分类。ERP初始化尚未执行。现有UTM Source是客户线索来源，MIWA Platform Store仅含乐天店铺，不替代为选品渠道。
