## 业务参数唯一来源

用户确认 ERP「设置 → 美和业务参数」为统一入口。AIONE导出器改为调用该入口现有 `miwa_ai.business_parameters_stage1.reference()`，复用返回的费用与汇率；没有新建参数表或修改公式。

当前入口的实际实现是引用既有 `AIONE Cost Settings`、原生 `Currency Exchange` 和 Item 默认值。草案保存不等于生效；必须通过入口中的现有费率编辑器、汇率维护入口修改有效参数。原有费用保存会触发ERP全商品重算，本轮未触发。

汇率25、平台费率10%、关税率10%、目标毛利率40%及物流包装参数继续标记试算。参数未确认不阻断其他验收；正式经营核算前由负责人确认。不能把代码哈希审核当作业务参数审核。
