# 员工统一认证：产品冻结与实施约束

状态：已部署并完成技术验收；86001邮箱人工核验及中国真实网络验收待完成。详见acceptance/2026-11-28-employee-auth.md。2026-11-28。

## 已确认范围

ERP8081 Employee为员工身份和业务授权唯一管理入口。复用people、person_login_emails、external_identities及人员投影。稳定员工编号关联原person_id，不重建人员、角色或业务资料。密码认证不使用个人邮箱密码，不提供自助注册。保留既有Google subject绑定，禁止凭相同邮箱首次自动绑定。

登录提供员工编号/邮箱共用输入、密码显隐、保持登录、管理员重置指引、Google入口。个人设置提供密码修改和既有资料/头像/退出入口。正式名称与LOGO不变。密码入口不等待Google脚本、字体或验证码；Google仅按需加载。

## 技术设计

- 认证凭据与可撤销会话保存在AIONE后端专用认证表，引用现有people；不进入ERP普通Employee字段或同步快照。
- 复用Node内置scrypt，随机盐，N=131072/r=8/p=1，32字节输出；密码15–128字符，允许粘贴和密码管理器，不裁剪密码。日志不得包含密码、哈希、会话令牌。
- 256位随机会话，数据库只存令牌摘要，浏览器使用Secure/HttpOnly/SameSite Cookie。统一覆盖密码及Google认证；修改/重置密码、停用、强退撤销所有会话。
- 首次临时密码24小时有效，仅获得改密能力，改密成功才允许业务访问。普通会话8小时绝对期限，保持登录14天绝对期限；服务端逐次核验员工状态和撤销状态。
- 登录失败限制同时按账号与可信入口地址执行，跨实例数据库共享计数；未知账号和错误密码采用一致提示和等价哈希工作。不信任客户端任意转发IP。
- 写入接口检查来源及CSRF；同源Vercel桥仅转发必要认证Cookie，正确传递Set-Cookie，禁止缓存和响应日志泄露。
- ERP管理操作必须原有System Manager及Employee写权限；临时密码不进入普通资料同步、审计内容或任务明文。复用本地出站HTTPS架构，不开放本地ERP端口。
- ERP临时密码使用RSA-OAEP包裹AES-GCM密钥的加密管理请求，经既有本机出站连接器传输；私钥仅云端认证服务持有。管理请求单独幂等回执，不混入普通员工资料快照。不在ERP保存明文密码或密码哈希。
- 邮箱唯一性、归属验证和Google subject验证为独立操作。邮件地址变更不能自动变更Google主体。尚未完成归属验证的邮箱不得生效。
- 管理员已确认邮箱核验方式：员工从新邮箱发送指定验证码到管理员，管理员核对发件地址及验证码并在ERP记录证据；验证码15分钟有效。无邮件服务接入。
- 停用/撤销需得到云端确认，ERP不得将尚未送达的撤销显示为成功；恢复网络前不能承诺即时远端撤销。
