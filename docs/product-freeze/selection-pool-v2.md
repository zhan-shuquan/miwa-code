# 美和AIONE选品池 V2.0

日期：2026-11-28。状态：产品范围已由用户确认，工程实现与验收中；尚未部署。基线：main 58e0385986d1f0f6f643d2559bd611bfa1a9bb6d。

## 业务与边界

复用 product_opportunities、现有选品录入工作台、选品编号服务、公司级查重、ERP员工权限、work_items 与 work_evidence。原始来源、原始链接、参考图片与原始选品人保留；采购资料及负责人独立维护。ERP 8081为唯一正式业务后台。

页面顺序：标题、可折叠来源入口、快速收集、阶段数量、筛选批量操作、卡片或列表。卡片支持4/6/8列，默认6，按员工记忆；小屏自适应。来源入口由ERP主数据提供，不在AIONE维护第二份渠道主表。

货源型机会认领后进入资料录入；市场型机会认领后先人工寻找1688同款。由真实资料、负责人、确认状态和ERP任务结果推导当前阶段及下一步，不用新手动状态替代已有业务事实。待办复用现有任务，未指定负责人时保持待分配，不能自动归给操作者或管理员。

员工实际操作与系统结果分别记录，关联员工、商品、时间、结果；业务日期采用Asia/Tokyo。重复点击、保存和重试不重复计成果。工作之家仅做数据与任务衔接，不重新设计页面。

## 1688导入：已确认入口

用户明确：当前1688 API没有读取选品库权限。本轮仅采用1688官方原始表格手动导出、AIONE自动导入；不研究API授权、不自动登录、不抓取网页。

原始表格无需员工改格式。复用现有XLSX/CSV与嵌入图片解析，读取标题、图片、商品ID、采购链接、参考采购价。共享收集入口的识别、公司查重、编号、原始选品人和工作记录。导入后统一进入选品池，支持批量认领、分配。

来源为1688且价格为明确单一金额时，将参考价作为新机会的初始采购价，员工可核对修改；不改任何已有商品的价格。价格区间等不可确定数据保留原文并提示待补充，不编造价格、不阻断商品收集。现有真实原始表格由用户提供后完成批量验收；程序生成样本不能代替真实验收。

## 发布门槛

开发分支验证后再合并部署。覆盖1688原始表格、社交链接加截图、同款采购关联、多人交接、阶段与下一步、任务与成果幂等、手机布局、后续录入与ERP兼容。使用86000及授权测试账号；真实员工独立权限验收仍为启用前单独事项。

保留已有编号、资料、目录、员工权限与同步配置；不修改8080；不付费生图、不上架、不采购。既有ERP会话混用、本地目录及共享WPS账号的权限问题不通过本任务擅自修改。

发布前保存稳定版本、备份与回滚记录，正式页面实际验证并提供截图；未验收事项不得标为通过。
