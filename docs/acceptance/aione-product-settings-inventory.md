# 商品资料与乐天录入：设置中心字段清单

以现有商品录入和已讨论的 RMS 流程为依据。本文件是开发清单，不是“全部已实现”的声明；平台限制以正式接口核验为准。

## 统一原则

- 共享之家 → 设置中心是同一数据源；各之家和商品编辑提供快捷入口。
- 设置中心维护字段定义、可复用资料、默认值、已有规则参数；采购价、实际重量、库存、条码和具体素材属于商品/SKU。
- 同一资料表可增加语言、图片、色值等字段；未使用字段可隐藏、选填，无须立即填全。
- 固定ID与显示名称分离。停用不破坏历史资料，默认项只用于新商品，删除检查保存商品的实际引用。
- 置顶优先，支持按实际引用量、人工顺序或名称排序；重复保存不增加引用数量。
- 新增资料不代表自动产生新计算逻辑或平台适配；必须注明接入哪个业务字段。

## 本轮基础资料验收

1. 设置中心“自定义分类与字段”添加商品基础资料模板，只进入草稿，原有自定义表不被覆盖；重复添加不重复创建。
2. 新增品牌或材质，保存生效后，商品原有字段直接可选，不再重复出现自定义下拉。
3. 修改显示名称，已有商品的业务引用值、资料ID不变；旧商品和停用值保留。
4. 旧商品尚无资料ID时，按业务值识别引用；保存时补齐稳定ID。重复保存、迁移前后引用数量不变。
5. 删除被旧值或稳定ID引用的资料均拒绝。并发安全复用共享参数锁与商品保存事务。
6. Excel导入导出保留业务引用值与资料ID；同表增加法语字段后仍使用原表。
7. 配套后端未声明能力时模板按钮禁用，不伪装接通。

仍需配套后端预览和真实商品验收后才能合并；本轮不执行生产参数写入。


## 第二批：规格、颜色与渠道多语言接入

- 显式添加“规格与颜色资料模板”到草稿，包含既有六类规格名称及常用八色。旧自定义表不覆盖；旧后端不开放安装入口。
- 新增规格名称后，可新建资料分类，将用途选为该规格的值表；按需添加日文/英文等字段。商品规格页直接选用，不再重复显示为商品自定义下拉。
- 每张值表最多一个用途，资料业务值/历史引用别名固定，显示名及语言字段可编辑。任意新语言字段仍可维护，但只有已接适配的日文/英文标准字段参与当前自动映射。
- 规格显示可按真实引用次数排序，商品已有规格值顺序保持。每件商品对同一资料最多计一次，不把多维SKU笛卡尔积当作多次引用。
- 保存事务验证新增/停用选项；旧商品未迁移也可保留。删除检查旧中文/日文规格文本；与商品保存共用参数锁。
- 乐天ItemAPI预览和已有受控发布计划读取当前设置，使用配置日文名称和值；缺失对应或日文选项冲突会阻断。代表颜色仍须匹配正式接口候选，资料新增不代表自动获得RMS候选资格。
- 既有乐天受控范围、图片核验、人工确认和权限均保留；没有扩大到任意商品自动上架。修改日文后，确认前会重建计划摘要。
- 商品/SKU固定业务值、SKU主键、SKU编码不随显示名或语言调整。规格值增删仍受原有已发布/图片关联检查约束。
- SKU表里的系统连携编号沿用原候选生成展示；本轮没有重写已发布平台编号。
- 本轮本地模型/Excel/DOM/乐天回归通过；新增独立数据库测试覆盖历史引用、精确计数、SKU身份和并发删除，最终结果以最新CI为准。配套后端及真实商品线上验收仍待完成。
