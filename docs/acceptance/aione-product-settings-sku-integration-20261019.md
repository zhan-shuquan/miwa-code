## 实现

- 复用设置中心、字段管理器、分类/品牌/材质/原产地、店铺及规格资料；不新增第二套资料源。
- 商品与 SKU 均使用共享包装、物流、配送目录，保留历史选项。规格翻译与历史持久化 SKU 编号和 #209 有效成本/售价同时生效。
- 编辑商品默认售价不清空独立 SKU 售价；成本/售价模式关闭仍保存差异。保留采购单个/整套计价规则与商品属性独立标签。
- 自定义商品选项的可见资料字段接入商品列表的“显示字段”，名称及字段变化由同一共享定义产生。
- 商品 Excel 增加自定义资料引用 JSON、稳定资料 ID 和可见字段投影；可编辑资料 ID，资料字段标为只读，改动投影不会改写权威设置。原格式仍可解析，成本与售价模式、零值及覆盖值保持往返。
- SKU 单独引用的中国包装、日本包装、物流纳入删除保护和实际商品引用统计，模式关闭也保护引用；每件商品对同一资料计一次。
- 上架只读预演同时使用配置的规格翻译和每个 SKU 的实际售价；不改变发布权限。
