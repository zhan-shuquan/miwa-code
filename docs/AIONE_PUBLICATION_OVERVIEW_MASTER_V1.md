# AIONE 概览电子出版物母版 V1

状态：正式锁定
适用项目：美和AIONE一体化工作平台（AIONE）

## 1. 正式定义

AIONE 中的“概览”不是普通 Dashboard、对象摘要或简单说明页。

“概览”正式定义为：

> 多功能电子出版物入口。

它将阅读、学习、工作指导、帮助、知识调用、传播与协作整合在同一页面体系中。

该功能定位长期保持稳定，不因具体工作台、之家、中心或业务模块变化而改变。

## 2. 核心内容能力

概览可承载但不限于：

- 电子出版物
- 工作手册
- 学习手册
- 帮助中心内容
- 业务说明
- 方法与 SOP
- 规则说明
- 新人学习
- 常见问题
- 重要更新

原则：一份知识，多处调用。

## 3. 核心交互能力

概览不仅用于阅读，还应逐步具备：

- 收藏
- 关注
- 评论
- 分享
- 转发
- 下载
- 打印
- 生成 PDF
- 复制链接
- @成员
- 查看版本
- 查看更新时间
- AI 摘要
- AI 问答
- 继续学习
- 关联业务页面
- 阅读记录
- 学习记录

## 4. 与业务页面的职责边界

业务页面负责“做事”。

概览负责“理解、学习、查规则、获得帮助并传播知识”。

两者必须双向关联：

- 概览中的章节可以直接进入对应业务页面或流程节点。
- 业务页面中的帮助入口可以直接打开概览对应章节。

## 5. 页面层级规则

在 AIONE 中，“概览”保留为工作台、之家、中心等模块的统一电子出版物入口。

对象详情页内部不得把“概览”作为普通对象摘要 Tab 使用，以避免职责冲突。

对象详情内部应使用更明确的命名，例如：对象信息、业务流程、核心数据、协作、附件、操作记录等。

## 6. 母版定位

正式母版名称：

**AIONE 概览电子出版物母版**

建议内部代码名：

`PublicationOverviewTemplate`

该母版未来由选品、测样、采购、视觉设计、上架发布、运营推广、订单与库存、客服与售后，以及各之家/中心统一复用；具体内容不同，出版能力保持一致。

## 7. 长期原则

- 概览不是普通首页。
- 概览不是 KPI Dashboard 的替代名称。
- 概览不是对象摘要页。
- 概览的核心是“电子出版物 + 工作手册 + 学习手册 + 帮助 + 知识传播”的多位一体。
- 功能可以逐步扩展，但定位不变。
