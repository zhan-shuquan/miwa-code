## 已实现

1. 保留现有平台外壳、导航、API、数据权限和动态布局。默认布局版本 37，左右 65/35；管理员可配置起始列、宽度、跨行、文本行数、分组、顺序和显示方式。
2. 市场参考链接默认一行，空值不再导致实时试算 URL 校验失败。市场附件空时紧凑显示上传入口，有附件展示内容；依据独占整行、默认六行，策略默认四行，均支持增高和放大编辑。
3. 商品图为白色正方形容器，与人工字段并排；ERP 简称、分类、品牌只读置于底部。材质和单位读取 ERP 选项作为输入建议，同时兼容历史模板文本。
4. 图片点击入口、整个区域的粘贴/拖放处理、连续上传队列和即时反馈修复；保留主图、排序、删除、预览。试算服务故障不会阻断草稿及图片保存。
5. 销售平台动态来自 ERP。当前实际只有 Rakuten；平台费率明确标注 ERP 统一试算费率，未冒充正式平台分类费率。
6. 四项运营金额直接复用被固定版本 ERP 脚本中原始运营费用表达式。物流零值注明“直发不适用”或“已包含”。左右运营费用也参与一致性校验，差额阻断提交 ERP，不阻断草稿。
7. 输入变化无需保存即触发试算，保留防抖、过期响应隔离及输入法保护。新记录实际售价不默认填入；售价突出显示，缺失结果为“—”，集中说明原因。
8. 保本售价、运营前利润、运营后利润采用统一双列指标。正常盈利绿色、亏损红色。数字箭头隐藏，工作台内数字输入通过委托事件阻止滚轮误改。

## 未完成或尚未验证

1. **多平台多方案、分类费率、平台负责人授权管理未实现。** 当前 ERP 缺少权威的平台分类费率及负责人模型。本轮依用户允许的安全收敛方式保留单平台能力与扩展标识；“增加销售平台”说明当前限制，不执行虚假新增。需先确定 ERP 主数据与权限契约，不能在 AIONE 复制第二套规则。因此跨平台费率及方案隔离测试不适用，未计入通过数。
2. **真实点击文件选择完成上传、真实操作系统文件拖放尚未通过浏览器验收。** 自动化文件选择被 Chrome 扩展未开启“Allow access to file URLs”限制；未擅自修改权限。粘贴、API 上传、持久化已通过，但不替代这两项操作的验收。
3. 白底图 AI 仍为未启用入口；主图可手工选择，未新增自动白底识别或“已确认白底”数据模型。
4. 部分商品简称可能未命中 ERP 识别规则，继续显示待回传且允许试算，不以猜测结果代填。

本轮可进行页面和单平台试算验收；多平台业务闭环及上述上传操作不能标记为完成。
