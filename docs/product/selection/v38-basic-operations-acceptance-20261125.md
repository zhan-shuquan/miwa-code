## 已实现

- 动态布局版本 38：商品基本信息、市场调研与选品依据、物流与包装、运营设置四个主要录入模块。采购来源并入基本信息，供应商独立模块隐藏，历史数据保留。第二阶段与历史区代码、接口保留，本轮录入页面不展开这些区域。
- 采购 URL 和长标题居顶；正方形图片旁为人工录入字段；库存采用 ERP 选项的标准下拉框；简称、分类、品牌为底部三列只读信息。默认布局来自配置，已有自定义布局做结构升级，不另造固定页面。
- 模块及成本分类图标复用公共 `semantic-icons.js`。新增计算器、价格标签、锁和排序箭头的公共 SVG，去掉菱形和文字装饰图标。
- 上传原图默认上限 20 MiB（20,971,520 字节）。前端读取同一后台配置，服务端 JSON 请求体上限包含 base64 膨胀空间。原图保存在原资产表；Sharp 生成最长边 1400 的 WebP 预览和最长边 240 的缩略图，保持纵横比，不裁切。
- 派生图使用有界 64MiB 服务端缓存，重启后按需重建；原始 bytes 和哈希不改变，ERP 资料包继续使用原图。像素解码上限为 8000 万，损坏图明确拒绝。
- 新草稿创建共用一个进行中的保存请求，避免商品图与市场附件并发上传生成不同草稿。保留分类隔离、排序、主图和删除操作。大小/格式帮助移到悬停提示，错误在成功后清除。
- 每个参考链接对应一个售价；支持新增、删除、打开及保存。沿用 `referenceLinks` 字符串数组，新增现有 JSON 数据内的 `referencePrices` 对齐数组，兼容旧 `marketReferencePrice`。清空售价不会被旧值复活，导入导出保留对齐价格。
- 选品依据默认九行，五项提示仅为 placeholder，不存成实际内容；保留自增高、手动调整和放大编辑。AI 入口置灰并使用悬停说明。
- 货号为深绿色链接，无货号显示“编辑草稿”；已提交/归档记录进入只读状态。按账号保存搜索、筛选、排序与分页位置。
- 表头排序由原服务端分页查询执行，白名单字段支持实际数值及时间排序，未计算利润和空值排在末尾。图片和货号固定左侧、表头固定；保留原批量、导入导出、列宽与显示配置。
- 保留实时试算、差额阻断提交、历史参数待验证、ERP 平台来源、统一试算费率、实际售价 48px/26px 强调、利润双列及负值红色。计算依据改为可展开信息，不长期占据操作空间。

## 后台配置

`AIONE_SELECTION_IMAGE_MAX_MB` 默认 20，允许 1–100。修改后重启 AIONE 后端，页面重新加载 `/bootstrap` 获取一致限制。新增依赖 Sharp 0.35.5 已锁定；未部署生产环境。

本地预览直接由 Express 接收请求，无额外反向代理限制。将来如另行批准部署，应同步检查部署平台/反向代理上限；本轮未变更这些外部环境。Excel 和 SKU 导入原有 2MB 限制不改变。
