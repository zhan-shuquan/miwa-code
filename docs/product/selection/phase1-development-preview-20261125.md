## 可操作预览

公司当前 Windows 电脑打开 http://127.0.0.1:8765/preview 。选择测试员工、测试合伙人或测试管理员；这是本机隔离预览账号，不修改真实 Google 账号或人员权限。

- 员工/合伙人：选品录入、图片、SKU、成本与预计利润、选品一览、筛选、复制、批量编辑、导入导出、归档恢复、提交开发 ERP。
- 管理员：同上，增加团队范围、表单布局、ERP 同步任务状态；删除仅限已归档且未提交 ERP 的草稿。
- 进入系统设置中的“表单布局”，可修改字段顺序、分组、宽度、显示隐藏、区块顺序/折叠与左右比例；保存在数据库，无需重新部署。
- 预览仅监听 127.0.0.1，不是外网或公司局域网共享地址。

页面使用现有 App Shell、Header、Sidebar、公共信息栏与 Footer。商品之家保留选品录入/选品一览。旧模块代码与数据保留，开发预览服务端拒绝所有未开放业务 API。修正原系统设置弹层对新增设置子路由的拦截；保留旧设置路由原有行为。

## 已实现的闭环

1. 认证后的 personId 作为所有者；客户端不能传入另一个所有者。列表、详情、修改、附件读取、导出与批量操作均在服务端校验归属。管理员使用既有可信管理员身份来源。
2. 在既有 product_opportunities 对象上增加 selection_workspace，复用 canonical 人员身份；没有建立第二套正式商品主数据。
3. ERP 导出的 DocType 字段、分类、品牌、选项、默认值、成本设置、汇率与价格表构成带版本快照。库存类型留空，必须人工选择；四项运营费率初始为零。
4. 直接执行经哈希锁定的 ERP 原始成本脚本与识别函数，未重写成本公式。缺失成本时显示待核算，所有预计利润固定为 verified=false。
5. 图片上传、主图、排序、预览/放大与删除；每张最多2MB。SKU表导入、独立SKU试算；读取实际“快速数据录入.xlsx”纵向模板；Excel/CSV批量新建预校验。
6. 草稿版本冲突校验；批量操作事务整体提交/回滚；复制带图片并清空货号；已提交记录不可覆盖。
7. ERP兼容资料包包含货号目录、货号.xlsx、SKU.xlsx、图片与追踪清单。模板明确“禁止上架”“禁止美工”。下载草稿前先保存当前内容。
8. 提交形成 selectionId + version 唯一任务。连接器主动拉取，租约防止过期执行者覆盖结果；失败可重试；参数变化阻断提交；ERP断线时保留最近快照与待处理任务。

布局配置当前覆盖ERP核心业务字段；图片、SKU和审计记录仍使用专用组件。普通附件、批量资料包下载、完整人员编号/选品代码展示尚未纳入本轮实现。现有已锁定选品编号规则未修改；用户填写的是 ERP 商品货号，不把它作为新的选品流水编号规则。

## 重启与交接

在本仓库执行：

```powershell
./apps/systems/aione/backend/scripts/start-selection-preview.ps1
```

该脚本只启动命名的独立开发容器及隐藏Node进程，不重启ERP容器。需现有 Docker Desktop、Node、本机已创建的两个开发容器和 .local/erp-snapshot.json。进程ID与日志写入 .local/selection-preview.*、.local/selection-connector.*。连接器默认60秒同步一次；服务未安装为系统开机任务。

线上启用前仍需完成：真实Google员工/合伙人账号映射验收、生产全量schema迁移预演、旧API/搜索/AI对象访问路径的完整隔离审计、云端部署与网络认证验证，以及ERP正式业务建档接收适配。这些未在当前测试中假定通过，也未通过打开发布权限来绕过验证。

回滚开发预览时，只停止以上两个本地Node进程及两个aione-selection开发容器即可；无需修改8080、8081 ERP或线上AIONE。数据库保留以便审查；不执行删除卷或删除测试资料的隐式清理。main基线备份位于项目output/aione-main-before-three-homes-20261125.bundle。
