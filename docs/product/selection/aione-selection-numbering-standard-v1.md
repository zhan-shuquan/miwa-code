# AIONE选品编号标准 V1｜Product Freeze

状态：CURRENT FOR PRODUCT FREEZE
日期：2026-09-08
适用项目：美和AIONE一体化工作平台

## 1. 选品编号格式

选品编号统一采用：

```text
xpYYMMDDNNN
```

示例：

```text
xp260908001
xp260908002
xp260909001
```

含义：

- `xp`：选品。
- `YYMMDD`：选品业务日期。
- `NNN`：当日三位流水号，从`001`开始。

## 2. 生成规则

- 由AIONE系统自动生成。
- 员工只读，不允许手工输入或修改。
- 每个自然日流水号重新从`001`开始。
- 同一日期内按创建顺序递增。
- 重复导入同一外部商品机会时，不重新生成选品编号，继续沿用原编号。
- 数据库必须保证`selection_no`全局唯一。

## 3. 日期来源

- 从1688选品池导入时：优先采用1688导出中的“加入时间”作为选品业务日期。
- 在AIONE中直接创建时：采用创建当日作为选品业务日期。
- AIONE仍应独立保存真实时间字段，不依赖解析编号进行业务计算。

## 4. 每日选品数量

由于选品编号按日生成，员工可以从编号直观看出选品日期和当日顺序；但正式统计必须基于结构化日期字段，而不是解析编号。

AIONE应能够直接统计：

- 今日选品数量
- 每日选品数量
- 每人每日选品数量
- 各分类每日选品数量
- 每日通过数量
- 每日淘汰数量
- 后续可进一步计算选品通过率、上架率、出单率与盈利率

## 5. 与正式商品ID的关系

选品阶段：

```text
xp260908001
```

商品通过选品并创建正式Product后，再生成美和正式商品ID，例如：

```text
mh0000002
```

二者永久关联：

```text
ProductOpportunity.selection_no = xp260908001
Product.product_id = mh0000002
```

选品编号用于追溯商品机会来源与选品过程；美和商品ID用于正式商品、SKU、图片、渠道与后续经营。

## 6. 前台显示原则

V1前台保持简单，核心显示：

```text
选品编号：xp260908001
负责人：小于
```

创建人、创建时间、更新时间等由平台统一审计能力自动记录，不新增重复业务字段。
