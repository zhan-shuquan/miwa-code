# AIONE商品机会自动分类标准 V1｜Product Freeze

状态：CURRENT FOR PRODUCT FREEZE
日期：2026-09-08
适用项目：美和AIONE一体化工作平台

## 1. 核心结论

1688选品池不要求员工预先分组，也不要求填写标签。

员工只负责将候选商品加入1688选品池并导出数据；AIONE负责基于导入商品信息自动匹配AIONE已锁定的分类体系。

人工只处理无法可靠自动分类的异常项。

## 2. 分类唯一事实源

AIONE分类中心维护唯一正式分类树。

当前采用已锁定的三级分类体系：

```text
一级分类
-> 二级分类
-> 三级分类
```

自动分类只能从AIONE现有正式分类节点中选择，不允许AI自行创建新的正式分类。

场景、季节、长度、商务、休闲、防晒、加厚等信息应进入属性或标签，不得因为标题出现这些词就擅自扩展正式分类树。

## 3. 自动分类输入

V1优先使用：

```text
source_category      1688原始类目
source_title         商品标题
source_cover_image   商品主图
```

如来源文件中存在以下信息，可作为增强输入，但不是前置必填：

```text
source_group
source_tags
source_note
```

因此，1688选品池可以不分组、不写标签。

## 4. 判断顺序

自动分类优先采用确定性技术，再使用AI处理不确定项：

```text
已知类目Mapping
-> 标题规则/关键词
-> AI结合标题、原始类目与图片判断
-> 人工异常确认
```

已能通过规则稳定确定的商品，不调用AI重复判断。

## 5. V1重点范围

第一阶段优先把当前真实业务重点分类跑准：

```text
女袜
男袜
女帽
男帽
```

例如：

```text
男士秋冬加厚中筒商务袜
-> 01 服装服饰 -> 袜子 -> 男袜
```

其中：

```text
秋冬 / 加厚 / 中筒 / 商务
```

属于属性或标签，不成为新的三级分类。

## 6. 自动与人工边界

### 自动通过

当规则或AI能够可靠匹配到唯一AIONE三级分类时，系统自动写入正式分类。

### 待确认分类

以下情况进入异常确认：

- 无法匹配到现有分类
- 多个分类冲突
- 标题与图片明显冲突
- 来源类目异常
- AI置信度不足
- AIONE分类树尚未覆盖该商品

人工只处理这些异常项。

## 7. 员工体验目标

员工日常操作：

```text
看到商品
-> 加入1688选品池
-> 每日导出
-> AIONE自动导入
-> 自动编号
-> 自动去重
-> 自动分类
-> 进入待判断
```

员工不需要逐条手工分类。

## 8. 统计要求

每次导入至少可统计：

```text
自动分类成功数量
待确认分类数量
分类失败数量
```

后续可分析不同来源、不同分类的自动分类准确率。

## 9. 治理原则

AIONE分类树由分类中心统一管理。

任何自动分类模型、Mapping规则或Prompt都只能消费CURRENT分类标准，不得形成第二套分类定义。

如果真实业务持续出现无法归类的商品，应回到分类中心评估是否需要调整正式分类，而不是让AI临时创建新分类。

## 10. 当前锁定结论

> 1688选品池可以不分组、不写标签。

> AIONE必须能够仅依赖导出的基础商品信息完成自动分类。

> 分类执行顺序：Mapping Rule -> AI Classification -> Human Exception。

> 人工只处理异常，不承担日常逐条分类工作。
