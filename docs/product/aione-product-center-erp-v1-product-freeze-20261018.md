# AIONE 商品中心 ERP V1.0｜Product Freeze 工作稿（2026-10-18）

状态：VALIDATING / 未经业务验收不得标记 CURRENT。

## 目标与边界
建立真实可用的商品中心，不再增加第二套商品、SKU、图片或上架数据。优先复用现有 Product Entry API、ProductAsset、SKU 和共享成本计算引擎。员工只看业务信息；系统标识、API映射和审计默认不暴露。不能以假数据或前端 localStorage 冒充真实持久化。

## 导航
商品中心点击名称默认进入商品列表，并展开子导航；箭头单独控制展开。
1. 商品列表
2. SKU列表
3. 图片列表
4. 上架链接

发布中心管理平台发布批次、任务、API提交、回查和失败重试；上架链接只读平台-店铺商品关联。四种导航按上述顺序显示，业务名称可配置但稳定内部ID不改变。

## 全局 ERP 工作区
支持已打开页面标签：选择返回已打开页面、关闭标签、未保存数据提醒。不要与单商品内的业务标签混淆。

## 统一可复用列表组件
分页默认20，选择20/30/50/100；行高约30px；关键词查询、筛选、表头三态排序及多列排序；按字段类型正确排序（金额/日期/数字）；拖动列顺序和列宽；双击列界自动适配；按内容/表头一键适配且设置最大宽度；配置列显示与隐藏；保存每人个性化列宽/顺序/可见性/筛选；恢复默认。筛选与跨页勾选不得互相破坏。业务操作包含新增、编辑、复制、启停、删除（确认/权限/关联保护）、批量修改、导入导出与分享，操作需要权限和预览变更影响。各列表复用组件而非复制实现。

## 商品列表
左分类树 + 中紧凑商品表格 + 可关闭的右侧快捷栏（默认不挤占主要表格）；右侧优先采购与各店铺商品直达链接，非大图片区。图片列默认隐藏。默认业务列：商品货号、名称、分类、品牌、SKU数量、采购价、售价、单件预计利润、利润率、状态。预计利润不等于真实订单利润；多SKU须明确商品汇总策略。内部编码与版本默认隐藏。分类树只读消费分类中心唯一分类；需要编辑时调用相同分类维护窗口。

## SKU列表
每行一个 SKU；关联唯一商品；显示规格、商品及SKU真实属性、库存、售价、状态，商品默认价格与SKU独立价格切换共用同一数据源；未证实库存不得冒充真实库存。

## 图片列表
一行一个商品货号，横向呈现白底 _ma、初始主图 _01、详情图 _02..._20 (至多19张)、SKU图 _sku01...、后续优化主图 _m01/_m02...。图片单元格小缩略图，组内过多缩略图折叠为 +N；图片URL默认隐藏，通过点击图片复制/打开或选择列显示。每张图在后端仍为独立 ProductAsset 记录，含归属、类型、版本、顺序、SKU绑定与平台关联。主图候选切换不意味着平台图片已经更新。乐天上架图组合最多20（主图1+详情图最多19），SKU图限额按实际接口额外验证；只限制发布清单，不删除额外候选素材。保留现有本地文件夹上传机制，不自动替换本地文件或发布到乐天。

## 上架链接
一行一个商品货号；图片小缩略图、货号、每个已登记店铺为一列，格中仅有效URL的打开图标，没有显示 —。店铺列表取唯一店铺注册表自动生成，新增店铺仅增加列；可以隐藏、排序，列多时横向滚动。一个商品在多个店铺映射多条 Listing；不复制 Product。URL按平台/店铺/上架返回信息产生与核验，不单凭货号猜URL。永井GD示例 https://item.rakuten.co.jp/global-dimensions/zsq005/；幸せ屋示例 https://item.rakuten.co.jp/happyhouse/zsq005/；这两个样例不代表公开状态已经核验。

## 商品录入表单
现有商品编辑页面为基础。业务标签：
1. 商品资料：基本信息、采购、物流包装、仓储基础
2. 商品属性：按分类动态字段（颜色/款式/尺码/材质/产地等）
3. 规格与SKU：员工选择销售规格，可多规格组合生成SKU，单SKU价格覆盖可选择
4. 利润分析：读取统一共享参数、确定性成本和利润计算
5. 上架资料：一次维护可跨平台复用的文案/图片/属性，平台特有字段归发布中心

当前标签职责基本稳定、显示名称可配置，业务实际需要时可加模块/标签；底层业务ID不因更名变更。商品属性独立于销售规格：即便选择「款式」为销售规格，颜色仍保留为商品/SKU真实属性，可映射乐天代表カラー等必填项；无足够信息显示待确认并阻断发布，GPT只作建议。商品资料右侧保留图片展示与管理，但商品列表不得固定大图片区域。

## 唯一字段配置
基础字段与自定义字段统一来自有版本和权限保护的字段注册定义；显示名称、单位、控件、默认值、必填、启停、表单标签与模块位置、行布局、列表可见性/搜索性及导入导出映射均由配置决定。员工个人列表显示配置与管理员字段架构修改权限分离。保存后再次打开表单和列表即可生效，无需代码部署。启停不可删除历史值；稳定字段ID不可随显示名称改动。计算字段/跨平台API映射必须使用经过验证的规则，不允许通过新增同名自定义字段冒充计算能力。

## 手工与本地导入
Excel商品/SKU、图片清单共用相同字段字典和身份键。新增、变更、跳过、冲突需先预览；默认不覆盖既有编辑数据。图片命名规则解析时，SKU绑定必须核验真实SKU身份。CSV/Excel导出遵循权限与当前选择范围。

## 发布边界
商品中心只维护商品、属性、SKU、图片和通用上架资料；发布中心支持单个/批量/授权自动上架，执行统一平台规则/API校验与结果回查。商品×平台×店铺是独立 Listing 关系，失败独立处理，默认不自动提交活跃商店。

## 验收门槛
1. 在 Preview 用真实测试商品完成：新增 → 保存 → 列表查询 → 再开编辑 → 保存 → 重新读取，并核验 Cloud SQL 持久化。
2. 系统内新增属性/字段后，表单、商品列表可选列、导入导出映射同步可用，不修改代码。
3. 图片按商品聚合、预览、命名类型和乐天图片数量阻断正确；SKU图片关联可核验。
4. 上架链接能根据真实店铺记录新增列，正确打开指定店铺且不推断未验证链接。
5. 列表排序、列宽双击适配、列顺序和个人设置、分页、筛选、批量影响预览实测通过。
6. 利润使用已有确定性引擎；多SKU差异、真实属性与销售规格分离。
7. 通过 typecheck/lint/build/契约/无重复路由或组件/回归检查；真实API和浏览器Preview验收后才能合并main。
