# 1688采购助手能力审计 V1

状态：CURRENT DRAFT / 已验证事实优先
日期：2026-09-08
适用项目：美和AIONE一体化工作平台

## 1. 目的

记录1688官方采购助手在真实操作中已验证的能力，作为AIONE后续集成与自动化设计的事实基础。本文不把页面猜测视为正式能力，只记录已验证或明确标注待验证的内容。

## 2. 当前总体结论

1688官方API暂不作为AIONE当前业务闭环的前置依赖。当前优先采用采购助手的文件导出能力完成半自动接入，未来API审核通过后再替换数据入口，不改变AIONE内部对象模型与后续工作流。

当前确认的三类核心输入：

1. 选品池Excel：商品机会与人工初筛信息。
2. SKU Excel：SKU结构化事实。
3. 商品素材ZIP：主图、SKU图、详情图、视频原始素材。

三者以1688商品ID作为外部确定性关联键。

## 3. 选品池

### 已验证能力

- 商品加入选品池。
- 自定义分组。
- 批量移动分组。
- 多标签。
- 备注。
- 搜索与筛选。
- 价格趋势页面查看。
- 导出全部或选中商品。

- 序号
- 商品标题
- 商品ID
- 商品链接
- 图片地址
- 商品价格
- 加入时间
- 平台

- 标签

多标签以逗号分隔导出，例如：`冬款,商务袜`。

### 当前限制

价格趋势可以在页面查看，但当前选品池Excel未发现历史价格序列导出字段。

## 6. 商品素材下载

### 推荐候选方式

`下载为压缩包 -> 多文件夹`

已在袜类与太阳能庭院灯两个不同商品上验证相同结构。

ZIP文件名包含1688商品ID，例如：

`1688_1066371500004_商品名称.zip`

ZIP内部结构：

```text
主图/
  主图-1.jpg
  主图-2.jpg
  ...
sku图片/
  sku-1-SKU名称.jpg
  sku-2-SKU名称.jpg
  ...
详情/
  详情-1.jpg
  详情-2.jpg
  ...
视频/
  视频-1.mp4
  ...
```

### 已验证规则

- 主图数量动态，不可假设固定数量。
- 详情图数量动态。
- SKU数量动态。
- 主图、详情图、视频保留顺序编号。
- SKU图片文件名包含顺序与SKU名称。
- 视频格式样本为MP4。

### 已发现异常

ZIP详情目录可能包含约1KB、可正常打开但几乎纯白的低信息图片。直接下载方式在同一商品中未出现该空白图。

因此AIONE未来导入必须包含Media Validation，而不能直接将ZIP内所有文件视为有效素材。

## 7. URL输出

已验证输出形式主要为HTML图片标签：

`<img src="https://...jpg"/>`

当前确认：

- 可取得图片URL。
- 视频不会导出。
- 当前输出不保留主图/SKU/详情的明确结构化角色信息。
- 不包含SKU ID、SKU名称等正式业务字段。

定位：辅助/Fallback图片URL来源，不作为AIONE当前标准素材导入主链路。

## 8. 选品情报能力

已确认采购助手包含：

- 趋势热点
- 热搜榜
- 热销趋势榜
- 牛商榜
- 店铺上新
- 代发下游榜单

### 趋势热点数据说明已验证

- 全网话题热度：近7日下游媒体平台相关搜索、内容曝光、互动等热度信号。
- 下游搜索增速：近7日下游消费者电商平台相关搜索趋势。
- 下游成交增速：近7日下游消费者电商平台相关成交趋势。

### 热搜榜已验证展示

- 近30天搜索热度
- 近30天点击热度
- 近30天点击率

注意：热度值应视为平台指标，不应未经口径确认直接解释为绝对搜索次数。

### 热销趋势榜已验证展示

- 热销榜
- 趋势榜
- 7天/30天周期
- 下游平台筛选
- 热销指数/趋势提示

### 牛商榜已验证筛选/指标

- 类目
- 商家身份
- 诚信通年限
- 先采后付
- 密文面单适配
- 近30天分销严选成交金额
- 近30天分销严选动销商品数
- 近30天累计铺货次数
- 近30天分销严选订单数
- 月代发总量

定位：用于供应商分销与代发能力判断，不等同于具体商品质量判断。

## 9. AIONE集成边界（当前）

1688采购助手负责：

- 外部商品发现
- 趋势/榜单辅助
- 候选收藏与轻量初筛
- SKU事实导出
- 原始素材导出

AIONE负责：

- 正式商品机会对象
- 公司内部协作
- 负责人/状态/评论/@/关注/附件
- 日本市场判断
- 成本利润
- SKU正式建档
- 商品视觉资产生产
- 发布与后续经营闭环

## 10. 当前未锁定/待继续验证

- AI作图实际能力与输出质量。
- AI标题生成是否适合日本市场。
- 商品尺寸标注能力。
- 铺货中心支持的平台、字段、同步能力。
- 颜色x尺码等多维SKU在素材目录中的稳定映射规则。

## 11. 当前实施原则

1688 API继续保留为未来自动化升级路径，但不阻塞当前AIONE开发。当前以文件驱动集成为主，后续API仅替换输入层，不改变AIONE内部ProductOpportunity/Product/SKU/MediaAsset等统一对象。
