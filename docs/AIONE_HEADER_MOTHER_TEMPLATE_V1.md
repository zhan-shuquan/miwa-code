# AIONE Header Mother Template V1

Status: 正式锁定（平台级母版原则）

## 1. 定位

Header 是美和AIONE一体化工作平台的“头部大脑”。

它负责承载跨工作台、跨业务区域的高频全局能力，并保持清晰、稳定、可扩展的导航逻辑。

## 2. 锁定范围

Header 不是所有层级一起硬锁定。

### 第一行：平台级母版，正式锁定

第一行承担 AIONE 的全局高频导航，是最核心、最稳定、最具美和特色的导航层。

第一行应体现清晰的业务与认知逻辑，不作为普通快捷栏处理，也不得因单一页面或单一工作台需求随意改动。

原则：
- 平台级全局能力优先
- 导航顺序有明确逻辑
- 高频入口保持稳定
- 允许后续小范围增减，但必须按正式变更流程处理
- 不允许工作台自行改造第一行
- 不允许为了曝光率重复放置完整入口

第一行是 AIONE Header Mother Template 的核心锁定区域。

## 3. 第二行：轻量快捷层

第二行不是重型业务导航，也不作为平台核心信息架构锁定。

定位为轻量、高频、可调整的快捷入口层，可根据真实使用频率持续优化。

适合承载：
- 店铺快捷入口
- 常用工具
- 办公软件
- 外部系统
- 邮箱等高频跳转

原则：
- 做轻
- 少而高频
- 可横向滑动或折叠到“更多”
- 不与第一行争夺主导航职责
- 不把复杂业务树塞入第二行

## 4. 第三行：美和精神层

第三行用于承载美和精神、企业方法论、核心价值表达及需要长期稳定传达的文化认知内容。

它不是普通通知栏，也不是即时信息区。

原则：
- 体现美和长期稳定的企业精神与方法认知
- 表达应简洁、克制、长期可用
- 不堆叠临时业务信息
- 不与第一行全局导航、第二行快捷入口抢职责
- 具体呈现方式可以做轻，但语义地位保持稳定

## 5. 第四行：轻量即时信息层

第四行定位为低干扰、即时性的轻量信息区域，不作为主业务导航。

当前承载：
- 今日印象
- 重要通知
- 重要日程

原则：
- 做轻
- 信息密度受控
- 不抢占 Main 的主要工作空间
- 可根据实际使用效果持续调整
- 不将大量待办、复杂操作或业务流程堆入此层

## 6. 四层关系

Header 应形成稳定的层级关系：

第一行 = 平台大脑 / 核心全局导航
第二行 = 高频快捷入口
第三行 = 美和精神 / 企业精神与方法认知
第四行 = 轻量即时信息

核心原则：

> 第一行重逻辑、重稳定；第二行做快捷；第三行承载美和精神；第四行承载今日印象、重要通知、重要日程等轻量即时信息。第二行与第四行持续做轻，第三行保持稳定而克制。

## 7. 变更规则

第一行属于正式母版锁定范围，修改必须记录：
- 原内容
- 新内容
- 修改原因
- 影响范围
- 生效状态

第三行的“美和精神层”职责属于稳定结构，不应被临时信息替代。

第二行、第四行属于可持续优化区域，可根据真实使用频率、页面拥挤度和业务价值调整，但不得改变第一行与第三行的核心职责。

## 8. 开发要求

后续 Header 代码应尽量形成统一平台级组件：

`PlatformHeader`

各工作台和事业复用同一 Header 母版，不允许复制出多个独立 Header 实现。

业务页面仅通过配置决定需要展示的上下文内容，不直接修改 Header 核心结构。
