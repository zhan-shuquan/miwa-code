V1.9.39｜工作之家 V2.0 真实运行验证基线｜Windows更新指南

【基线】
V1.9.38 WORK HOME V2 FINAL CLOSURE CANDIDATE

【本版重新定位】
本版不再把“工作之家V2.0”称为最终锁定版，而是正式进入“真实运行验证基线”。
原因：真实讨论和使用继续发现了“我的工作连续时间视角、工作记录+可选总结、我的总结、跨对象关注”等高价值能力。
原则：结构先稳定运行，继续用真实业务验证；不因过早锁定阻止有价值的新发现。

【本版是否需要数据库迁移 / Backend部署】
不需要。
- 不新增0061迁移。
- Cloud SQL继续保持0060_object_reactions.sql。
- Backend继续使用V1.9.36工作之家执行/点赞/关注能力。
- 工作总结、Google Docs、A4 PDF、推广、跨对象关注仅完成前端结构/真实字段兼容准备；没有后端事实就不伪造成功数据。

【本版主要变化】
1. 工作之家Sidebar最新顺序：
   工作概览
   我的工作
   我的关注
   我的建议
   我的创新
   我的总结

   全部工作
   事业工作
   团队工作

   工作记录

   分组只用留白，不增加多余标题。
   “＋创建工作”从Sidebar移除，回到“我的工作”Main。

2. Header进入工作之家默认跳转“我的工作”。
   旧#/work-today保留兼容路由，但不再显示在Sidebar。

3. “我的工作”不再等于“日期=今天”。
   Main增加三个连续时间范围：
   - 今日以前：过去应推进但仍未闭环
   - 当前工作：现在需要行动、判断或跟进
   - 今日以后：未来已经安排的工作
   工作跨天不自动消失。

4. “我的工作 / 全部工作 / 事业工作 / 团队工作”统一复用同一个Work Item Browser。
   不再为团队工作单独设计一套Main。
   入口差异只来自预设查询、标题、范围和过滤条件。

5. “我的工作”Main保留高频“＋ AI创建工作”。
   点击打开美和AI，自然语言继续走既有Proposal → 人工确认 → Work Item真实链路。

6. 核心指标继续复用统一KPI能力，并可点击过滤：
   工作总数 / 待开始 / 进行中 / 等待中 / 待验收 / 异常。
   单行显示，空间不足横向滚动，不换成第二排。

7. Work Item列表时间字段明确分成：
   开始时间 / 截止时间。
   不再使用含义模糊的“时间”。

8. 工作记录继续存在，定位为所有闭环工作的真实事实账本。
   主字段调整为：
   完成时间｜工作事项/最终结果｜事业/项目｜负责人/来源｜闭环结果｜有效工时｜证据｜工作总结｜操作。

9. 工作总结不是每项工作的强制动作。
   只有少数有意义、有复用价值的工作，由本人主动决定总结；美和AI起草，人阅读判断、适当修改并确认。
   当前前端可读取真实summary metadata，并在工作记录显示：
   总结状态 / 团队推广 / 集团推广 / Google Docs / PDF。
   没有真实总结数据时只显示“— / 暂无总结”，不制造假文档。

10. 新增Sidebar“我的总结”。
    这是当前用户真实工作总结的个人预设视图，不建立第二份数据。
    当前正式总结对象/API尚未接入，因此没有真实总结时显示诚实空状态。

11. “我的关注”定位扩大：
    关注 = 订阅 + 快速定位 + 持续跟踪。
    当前Backend已接入Work Item关注；以后可按同一对象关系扩展到工作总结、商品等对象。
    本版没有伪造跨对象关注接口。

12. 页面主题字按当前章节区分：
    工 / 注 / 议 / 创 / 总 / 事 / 团 / 录。

13. Sidebar不再重复显示“当前空间”等冗余kicker。
    当前事业继续只由Header“事业之家 │ 当前事业▼”承担。

【浏览器重点验收】
A. Sidebar
- 顺序与本指南一致。
- 不出现“今日工作 / 等待中 / 异常处理 / 待验收 / 创建工作”。
- “事业工作”仍可展开具体事业。
- “我的总结”存在。

B. 我的工作
- Header进入工作之家默认来到“我的工作”。
- 顶部显示今日以前 / 当前工作 / 今日以后。
- 三个范围可切换，工作跨天不消失。
- 有“＋ AI创建工作”。
- 核心指标可点击过滤。
- 工作事项一览仍支持搜索、关系、事业、成员、状态、优先级、时间、更多筛选、排序、列表/卡片、刷新、12项分页。

C. 团队工作
- 与全部工作使用同一Work Item Browser母版。
- 通过成员/团队/事业等筛选改变视角，不再进入独立“成员目录Main”。

D. 工作记录
- 查看完成时间、最终结果、负责人/来源、闭环结果、工时、证据、工作总结。
- “总结状态”可筛选全部/有总结/无总结/团队推广/集团推广。
- 没有真实总结的工作不会出现假Google Docs/PDF。

E. 我的总结
- 没有真实summary metadata时显示诚实空状态。
- 有真实summary metadata时显示总结状态、摘要、正式资料入口。

F. 回归
- 点赞、关注正常。
- Work Item详情可打开。
- 开始执行 → 证据 → 提交完成 → 验收闭环不回归。
- Header工作提醒不回归。

【本轮明确不做】
- Work Summary正式数据库表/API。
- Google Docs自动创建/同步。
- A4 PDF正式生成与版本归档。
- 一键推广到团队/事业/全集团及系统通知/重要通知/我的工作预览。
- 商品/人员/项目/知识等跨对象关注与全局收藏。
- 组织上下级直接布置权限与平级工作请求。
- 美和日历Google Calendar授权问题。

这些能力已经明确方向，但继续按“先真实业务、再形成证据、再开发确定能力”推进。
