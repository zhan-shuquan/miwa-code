MIWA AIONE V1.9.33｜工作之家 V2.0 结构升级
Windows Safe 更新与人工验收指南

一、更新方式
1. 停止正在运行的本地 AIONE / Live Server / AI Backend。
2. 解压本次 ZIP，打开其中 code 文件夹。
3. 将 code 文件夹里面的内容合并/覆盖到 D:\miwa\code\ 。
4. 选择替换同名文件；不要先删除 D:\miwa\code，本次仍然是增量覆盖。
5. 本版修改了 Backend 工作之家读取/关注接口，覆盖后请重新启动 Backend，再启动 AIONE 页面。
6. GitHub Desktop 检查变更，人工验收通过后 Commit + Push origin。

二、本版不需要数据库迁移
- 关注机制复用既有 work_item_participants 表的 observer 角色。
- 没有新增第二套关注表、工作表或日历任务表。
- 既有 work_items / work_evidence / result_facts / business_events 事实链继续使用。

三、重点人工验收
1. 工作之家 → 工作概览
   - 页面应真正使用与美和之家/事业之家相同的数字出版母版；
   - 能看到封面/章节/页码/出版版式，而不是普通卡片页；
   - 《美和工作手册》应包含8章：工作之家是什么、为什么需要、美和工作9问、工作流动、人和美和AI、工作组织、与美和日历、当前工作动态。

2. Sidebar
   - 工作概览
   - 今日工作
   - 全部工作
   - 我的关注
   - 事业工作（可展开）
   - 等待与阻塞
   - 待验收
   - 工作记录
   - “我的工作”不再作为正式Sidebar入口。

3. 事业工作
   - 展开后可看到美和跨境、美和批发、美和采购代理、美和物流、美和留学、美和不动产、美和商务咨询、美和品牌；
   - 进入某事业后，只默认展示该事业工作；
   - 跨事业工作仍可通过“全部工作”查看和主动关注。

4. 全部工作 Work Browser
   - 卡片 / 列表切换正常；
   - 搜索工作名称、下一步、业务对象正常；
   - 关系 / 状态 / 优先级 / 事业筛选正常；
   - 只有真实存在团队/项目元数据时才出现相应筛选项，不显示示例假数据；
   - 排序支持 AI建议优先、截止时间、最近更新、优先级。

5. 关注机制
   - 在“全部工作”关注一个与自己无执行关系的工作；
   - 该工作应进入“我的关注”；
   - 取消关注后应从“我的关注”消失；
   - 仅因为关注，不应自动进入“今日工作”或Header待办红点。

6. 公司透明与权限
   - 公司公开工作可查看；
   - 非负责人/非执行关系进入详情时，应明确提示当前是查看/关注关系，无执行权限；
   - private / restricted / sensitive 工作不应被公司全景无边界读取。

7. 既有工作闭环回归
   - 自己负责的工作仍可开始执行；
   - 可添加执行说明/证据；
   - 可提交完成；
   - 创建者可验收；
   - 美和AI复盘仍正常；
   - Header 工作提醒继续只反映真正需要本人处理的工作。

五、当前边界
- “关注”已持久化并可查看最新工作状态，但本版没有单独建立关注动态推送订阅，避免关注自动变成待办。
- 团队/项目筛选只读取真实元数据；后续真实业务逐步补齐后自然出现。
- 美和日历继续按“Work Item 的时间投影”方向建设，本版没有创建第二套日历任务。
