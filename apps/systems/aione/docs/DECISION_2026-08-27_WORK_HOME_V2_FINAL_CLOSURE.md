# 2026-08-27｜工作之家 V2.0 最终收口结论

## 正式收口

工作之家从本版开始进入真实使用验证。开发主线转入美和跨境业务闭环，工作之家非阻塞问题统一进入待优化清单。

## 核心结论

- Work Item 是唯一正式执行对象；“任务”是工作的一种日常表达/分配形式，不建立第二套Task事实源。
- 人可以用自然语言交代工作，美和AI负责整理为结构化Proposal，人工确认后形成Work Item。
- 手动结构化入口是标准与兜底，AI是优先工作方式。
- 工作可以开放透明，但直接布置工作必须最终受组织责任和权限约束。
- 一个Work Item原则上只有一个最终负责人。
- 今日工作是当前用户执行视角；全部工作是当前用户权限范围内的全部可见工作。
- 事业工作是经营事业视角；团队工作是人/团队协同视角。
- 等待、异常、待验收是状态查询，不再占Sidebar章节。
- 工作记录是历史事实账本，不承担人才评价。
- 美和工作9问继续“验证中”，先运行再形成证据。
