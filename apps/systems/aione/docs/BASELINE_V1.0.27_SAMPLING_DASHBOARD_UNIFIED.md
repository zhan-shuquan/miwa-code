# AIONE V1.0.27｜测样工作台执行驾驶舱统一

日期：2026-08-21  
状态：CANDIDATE / 可运行验证版

## 本轮目标

纠正 02 测样工作台的页面层级：工作台根页面不再直接进入“测样概览”，而是与 01 选品工作台统一为执行型工作台首页。

## 本轮完成

- `#/sampling` 默认入口改为测样执行驾驶舱。
- 根页面与选品工作台统一母版：`工作台标题 -> 状态 -> 流程 -> 指标 -> 业务对象队列`。
- 页头右上只保留 `测样概览 / 测样任务` 两个工作台级入口。
- “待测样商品”从工作台页头下沉为业务对象队列，保留独立 `#/sampling-queue` 页面。
- 新增测样状态：`待测样 / 测样中 / 待复测·异常 / 已完成`，数量从当前 localStorage 预演数据和统一任务层计算。
- 新增测样流程：`待测样 -> 样品准备 -> 到货确认 -> 实物检查与实测 -> 形成结论 -> 回写选品`。
- 新增业务指标：测样商品总数、待测样、进行中、异常/复测、本周完成、平均测样周期、完成率。无可靠数据的平均周期显示“待验证”，不制造假数据。
- “当前测样商品”支持卡片/列表、搜索、状态筛选、负责人筛选与流程节点筛选。
- 无测样任务的商品可从工作台直接“建立任务并进入”，继续使用原有 `dedupeKey` 防重。
- 测样概览仍保留为独立认知页。上下游关系修正为 `选品工作台 -> 测样工作台 -> 回写选品工作台上架判断`，不再把采购/上架误画成测样的直接下游。

## 页面职责锁定

- 工作台首页：看状态、看流程、看指标、处理业务对象。
- 工作台概览：说明为什么、原理、规则、上下游关系。
- 工作台任务：按业务查看执行任务；与“今日工作”共用同一任务数据。
- 业务对象队列：待测样商品、样品、记录、报告等继续作为子页面。

## 验证

- `tests/verify-sampling-dashboard.mjs` 专项验证通过：根页面、子页面、路由与回写关系均已锁定。
- JS 语法检查通过。
- `tests/verify-global-shell.mjs` 通过：141 个内部入口，跨境 9 个工作台，批发 6 个业务闭环。
- 本版未改动选品、测样记录详情中的原有成本、定价、实测、报告和上架判断核心逻辑。
