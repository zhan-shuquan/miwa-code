# AIONE 商品图片命名标准 V1.0 — CURRENT (2026-10-12)

## 唯一命名约定

- 商品展示图：`{localCode}_01.png`、`{localCode}_02.png`……，不固定图片张数。
- 白底图：`{localCode}_ma.png`。
- **SKU / 规格 / 颜色图片：`{localCode}_c01.png`、`{localCode}_c02.png`……。** 不区分颜色图片和 SKU 图片两套命名。无论规格名称为颜色、款式、尺码、套数、型号还是其他，都使用 `_cNN`。
- 独立细节图：`{localCode}_d01.png`……（用于未来本地自动同步识别）。
- 实拍图：`{localCode}_r01.png`……（用于未来本地自动同步识别）。
- 扩展名允许 jpg / jpeg / png / webp；命名的扩展名必须与文件实际编码一致。
- 例：`zjl238_c01.png`、`zjl238_c02.png`。

## 兼容、对象关联与治理

- `_sku01` 及 `_skuNN` 为**废止的新增图片命名格式**，不得作为新文件、新默认值或新模板生成。
- 旧商品资料中明确保存的 `_skuNN` 文件名暂时只读兼容。不得自动重命名、覆盖或删除已有本地、GCS 或 R-Cabinet 图片。
- 通过商品内部 ID 和 SKU 稳定身份登记资产；`_cNN` 的 NN 仅用于导入展示排序，不得作为永久 SKU 身份。
- 本规范统一服务 AIONE 图片识别、本地同步助手及乐天图片发布；当前 PR 先修复默认文件名和商品中心识别，Windows 自动同步尚未实施。新增上传链路应复用唯一的 ProductAsset 和 GCS 底座。
- 如同一商品颜色图排序发生变化，需按业务 SKU 身份重新校验映射，禁止仅按编号直接覆盖。
