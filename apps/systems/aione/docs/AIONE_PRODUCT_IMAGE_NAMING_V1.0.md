# AIONE 商品图片命名 V1.0 — DEPRECATED

本文件原 V1.0 复杂图片命名规范已于 2026-10-12 被简化版 V1.1 取代，**不再作为 CURRENT**。

**唯一 CURRENT：** [AIONE_PRODUCT_IMAGE_NAMING_CURRENT.md](./AIONE_PRODUCT_IMAGE_NAMING_CURRENT.md)

正式员工操作只需：
- 商品展示图：`商品货号_01`（首图）、`商品货号_02`、`_03`……
- SKU 图：`商品货号_c01`、`_c02`……
- `gift` 通用素材以后另行设计；不设置固定 9/15 张限制。

废止的 `_ma`、`_dNN`、`_rNN`、`_skuNN` 不用于新的员工图片命名要求；历史图片保留、不得自动重命名或删除。
