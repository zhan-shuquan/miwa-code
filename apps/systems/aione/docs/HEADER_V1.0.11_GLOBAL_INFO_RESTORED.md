# Header V1.0.11｜全局信息与外部入口补全

## 本次范围

在 V1.0.10 两层主导航与现有 Sidebar 不变的基础上，仅补全此前遗漏的全局能力：

1. 恢复美和精神 433 快速展示与即时说明 Drawer。
2. 恢复今日信息（东京、日期、时间、农历、节气、星座）。
3. 恢复重要通知轻量槽位；无正式通知时显示空状态。
4. 恢复已确认的常用店铺与工具外部链接。
5. “更多店铺”改为 Header 内轻量面板，按平台预设：楽天市場 / Amazon / TEMU / Qoo10 / TikTok Shop。
6. “更多工具”改为 Header 内轻量面板，按用途组织，不新增独立下级页面。
7. 未从正式账号资产资料确认的链接继续留空，不猜测补齐（例如当前飞书入口）。

## 结构原则

- 第一层：平台、用户、今日工作、美和日历、五大全局能力、搜索/通知/帮助/设置。
- 第二层：当前高频店铺与工具。
- 第三层：美和精神（轻量常驻）。
- 第四层：今日信息 + 重要通知（轻量常驻）。
- 更多店铺 / 更多工具：Header 内弹出面板，不跳独立页面。
- Sidebar 继续保持 V1.0.9/V1.0.10 已确认的事业化导航，不在本次修改。
