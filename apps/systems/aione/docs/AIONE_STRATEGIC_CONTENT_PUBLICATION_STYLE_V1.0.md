# AIONE 战略内容型页面母版 V1.0

参考来源：用户确认喜欢的《美和集团AI执行总架构 V0.1》PPT设计与排版。

## 适用范围

适用于美和之家、事业之家、集团战略、经营架构、理念文化、事业说明、知识说明等“认知/内容型 Main”。
不适用于表单、列表、任务、订单、采购、库存等“业务执行型 Main”。

## 信息表达原则

1. 一个页面只承担一个核心主题。
2. 页面顶部使用章节编号 / 英文小标题 / 大结论标题 / 简短说明。
3. 主体优先使用 3—4 个卡片、关系板、流程、架构或结论条；避免连续大段文字。
4. 大量留白、清晰分区、稳定字号层级，不使用促销海报式视觉。
5. 互动按钮仍执行AIONE企业级SaaS规范；内容版式可以具有“企业宣传册/战略PPT”的出版感。
6. 页面从一开始兼顾 A4 PDF 打印/导出，做到网页、内部资料、宣传册可以复用同一内容结构。
7. 美和品牌主色仍以绿色体系、暖白和中性色为主；PPT的“战略感”主要继承排版与信息秩序，不擅自扩张新的品牌主色。

## 页面标准结构

章节编号 / EYEBROW → 大标题 / 一句话结论 → 简短说明 → 3—4核心模块 → 重点结论带 → 图表/架构/关系/流程 → MIWA/版本/状态。

## 长期目标

内容型页面不是把PPT嵌入网页，而是把美和已经验证舒服的PPT信息语言转成AIONE可复用的数字出版母版。
