## Work Item Browser

全部工作采用统一逻辑：

`搜索 → 关系 → 事业 → 成员 → 状态 → 优先级 → 时间 → 更多筛选 → 排序 → 显示方式 → 刷新 → 分页`

- 默认12项/页。
- 列表 / 卡片2、3、4、6列继续记忆个人偏好。
- 排序包含美和AI建议优先、优先级、截止时间、最近更新、最近创建。
- 全部工作默认最近更新；今日工作默认美和AI建议优先。
- 今日工作是执行入口，不是“时间=今日”的筛选项。

## 创建工作

“＋ 创建工作”优先打开美和AI，自然语言生成结构化 Proposal，经人工确认后进入统一 Work Item。

当前正式能力仍以既有 Proposal → Human Confirm → Work Item 为准。本版不伪造完整跨用户任务分配权限。

未来组织权限应区分 created_by / assigned_by / responsible / participants / reviewer，并遵循：

- 工作可开放查看，但直接布置工作需要组织责任边界。
- 管理者对管辖成员可直接布置。
- 平级成员原则上形成工作请求。
- 一个 Work Item 原则上只有一个最终负责人。

上述权限关系属于后续正式组织/人才权限阶段，不阻塞本版封版。
