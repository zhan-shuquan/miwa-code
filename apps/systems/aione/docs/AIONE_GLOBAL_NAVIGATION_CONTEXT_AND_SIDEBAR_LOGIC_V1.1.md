# AIONE全局导航与页面上下文逻辑说明 V1.1

- 文档ID：`KNOW-AIONE-NAV-CONTEXT-V1`
- 归属：知识之家 → 帮助中心
- 状态：正式锁定（Header核心逻辑）；Sidebar具体菜单继续进入第2阶段验证
- 生效日期：2026-08-24
- 适用系统：美和AIONE一体化工作平台

## 1. Header为什么重要

Header不是普通菜单条，而是AIONE的“头部系统”。它首先建立当前工作的认知与上下文，再提供进入长期业务空间和高频资源的路径。Header不稳定，Sidebar、Main、Aside和后续页面都会反复返工。

## 2. H1第一行：上下文 + 核心之家

第一段顺序永久遵循：

**公司 → 事业 → 用户（使用者） → 工作 → 时间**

映射为：

**Logo + AIONE → 当前事业 → 当前用户 → 工作之家 → 美和日历**

然后进入核心长期对象之家，当前顺序锁定为：

**人才之家 → AI之家 ｜ 客户之家 → 供应商之家 ｜ 分类之家 → 商品之家 ｜ 分析之家 → 知识之家**

其中：

- 人才之家与AI之家相邻：人才负责、管理和使用AI，关键责任保留给人。
- 客户之家与供应商之家相邻：客户是价值输出端，供应商是资源输入端。
- 分类之家与商品之家相邻：分类定义长期经营归属，商品承载具体经营对象。
- 分析之家把事实转为理解和判断；知识之家维护正式知识源。
- 店铺不再作为一级“店铺之家”常驻Header；店铺后台属于高频共享资源快捷入口。
- “共享之家”正式取消。共享资源不是之家。

第一行右侧全局工具继续为：

**全局搜索 → 通知 → 帮助 → 设置**

帮助图标只是一条快捷路径，正式归属仍是：

**知识之家 → 帮助中心 → 具体帮助文档**

## 3. “更多”机制

第一行不无限增加之家。未来出现新的正式之家时，先判断是否达到核心常驻价值；非核心扩展之家进入“更多”。没有真实扩展之家时，“更多”槽位自动隐藏，不为空占位。

## 4. H2第二行：高频共享资源快捷入口

第二行的唯一目的：**让高频资源一步到达。**

因此不再显示“店铺之家”“应用之家”等分类按钮。快捷资源按照后台元数据自动排序和分组，前台只用细分隔符区分，不增加一层文字分类。

当前可包含：

- ERP等内部高频应用
- 幸せ屋、PrimeLife、永井GD等店铺后台入口
- Robot-in、佐川、黑猫、福山等订单/物流资源
- GPT、WPS、飞书、Google Drive等办公资源
- Amazon、楽天、箱ワン等采购资源
- Gmail等通讯资源

第二行末端提供“全部资源”，进入**共享资源**页面。

## 5. 共享资源统一模型

正式名称：**共享资源**。

共享资源是平台级统一资源目录和管理页面，不是一个“之家”。它管理所有可共享资源，不再区分“共享资源”和“共享能力”两套概念；能力也属于资源。

资源的产品形态统一为：

**应用 / 工具 / 知识 / 代码 / 数据 / 模板 / 连接 / 服务 / 其他**

“内部 / 外部”是资源属性，通过字段、标签和筛选体现，不拆成两套页面体系。

资源至少具有：

- 产品形态
- 内部 / 外部属性
- 正式来源或入口
- 负责人和权限
- 使用频率
- 是否进入Header快捷层
- Header排序分组
- Header隐藏字段
- 当前状态

重要原则：**正式归属/正式来源与快捷呈现分开管理。**

例如ERP属于共享资源，产品形态是应用；因为高频，可以同时出现在Header第二行。HR同理属于应用，可登记在共享资源中，并根据成熟度决定是否显示快捷入口。

## 6. Header第2行自动分类与隐藏

Header不维护第二份资源清单，而直接读取共享资源注册数据。

- `quickAccess = true`：允许进入Header快捷层。
- `headerHidden = true`：资源仍保留在共享资源目录，但Header隐藏。
- `quickGroup`：只用于自动排序与插入分隔符，不在前台显示“店铺之家/应用之家”等分组标题。
- `sortOrder`：控制同组资源顺序。

这样资源增加、隐藏、改名或调整分组时，只修改一份资源定义。

## 7. 供应商之家边界

供应商之家是一级长期对象之家，不是采购工作台子功能。

供应商之家回答“供应商是谁、能供应什么、长期表现如何”；采购工作台回答“一次具体采购如何完成”。供应商资料可以被商品之家、采购工作台、ERP、库存和分析之家共同引用，不重复维护。

## 8. 五区职责继续保持

- Header：建立全局上下文、核心之家和高频资源入口。
- Sidebar：根据事业 → 模块/之家 → 页面类型 → 当前上下文动态生成业务路径。
- Main：完成当前主要工作。
- Aside：只提供上下文辅助、风险、帮助和AI支持。
- Footer：低干扰提供系统可信度、环境、版本和生态连接。
