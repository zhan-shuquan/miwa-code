# AIONE V1.9.25｜美和之家 Google Drive 原件绑定 Candidate

## 1. 本轮目标

V1.9.25不再扩目录、不重做页面，而是完成“企业资料”从索引页到正式原件入口的关键一步：

> AIONE目录 = Google Drive目录 = 美和AI未来检索目录。

集团核心资料只维护一份正式原件。AIONE保存资料身份、版本、权限、内容Route与Google Drive File ID；员工从AIONE直接查看或下载原件。

## 2. Google Drive镜像目录

正式内容根目录：

`美和集团资产库｜MIWA Group Assets / 美和之家｜AIONE内容源`

其一级目录与AIONE美和之家保持一致：

- 00_美和概览
- 01_集团介绍
- 02_理念与文化
- 03_经营与战略
- 04_事业与全球
- 05_组织与治理
- 06_品牌与价值
- 07_发展与动态
- 08_企业资料
- 09_外部连接

V1.9.25新增 `js/data/miwa-google-drive-registry.js`，集中登记已确认的Drive Folder ID与File ID，避免把外部资料位置散落在多个页面组件中。

## 4. AIONE页面行为

企业资料行现在区分：

- **看内容**：进入AIONE结构化内容Route；
- **查看原件 ↗**：打开Google Drive中的当前原件；
- **下载原件**：调用Google Drive File ID对应的下载地址。

未绑定正式原件的资料继续显示“原件待绑定”，不得伪造URL。

## 5. 为美和AI准备的来源字段

`getMiwaCompanySearchRecords()` 的资料记录新增：

- sourceId
- sourceType
- sourceUrl
- downloadUrl
- sourceFolderId
- sourceName

因此下一阶段美和AI可以在找到资料后，同时说明来源并返回正式原件。

## 6. 长期责任边界

默认自动化/AI可以承担：

- 建目录与归类建议；
- 文件索引与File ID绑定；
- 版本识别；
- 摘要、标签、搜索索引；
- AIONE页面与Drive原件关联；
- 重复和过期资料检查。

以下高风险动作仍需人类负责人确认：

- 删除正式资料；
- 覆盖当前正式版本；
- 改变对外公开状态；
- 重大权限调整；
- 废止集团级正式规则或资料。

## 7. V1.9.25验收重点

1. 10份集团核心资料均存在Google Drive File ID；
2. AIONE不再显示这10份资料“原件待绑定”；
3. “查看原件”可打开Google Drive；
4. “下载原件”使用独立下载URL；
5. V0.1内容状态保持不变；
6. Drive Folder ID与AIONE目录集中登记；
7. 美和AI搜索记录能够返回来源ID与来源URL；
8. 原有美和之家目录、Main、Aside、PDF出版模式不被重建。
