# AIONE V1.9.2 CANDIDATE｜知识之家帮助中心与导航逻辑基线

日期：2026-08-24

## 本轮定位

V1.9.2不启动Sidebar第2阶段代码重构，只完成第1阶段确认后的信息架构收口与正式知识沉淀：

1. 保持已确认Header核心上下文链不变：`公司 → 事业 → 人 → 工作 → 时间 → 业务执行`。
2. 在共享“之家”组中补入`知识之家`。
3. 正式取消“帮助之家”，帮助快捷入口改为`知识之家 → 帮助中心`。
4. 将《AIONE全局导航与页面上下文逻辑说明 V1.0》加入知识之家正式知识源。
5. 支持通过`#/knowledge-home?type=帮助中心`直接进入帮助中心筛选视图。
6. 增加知识正文阅读器，使带正文的正式知识可以在系统内直接阅读。
7. 已有LocalStorage知识数据不会阻止新正式知识种子补入。

## Header锁定顺序

### 工作上下文链

`Logo + AIONE → 当前事业 → 当前用户 → 工作之家 → 美和日历`

### 共享之家组

`分类之家 → 商品之家 → AI之家 → 分析之家 → 知识之家 → 共享之家`

### 全局工具

`全局搜索 → 通知 → 帮助中心快捷入口 → 设置`

帮助图标只是快捷入口，不是独立“帮助之家”。

## 帮助中心正式关系

`知识之家 → 帮助中心 → 具体帮助文档`

正式帮助文档ID：`KNOW-AIONE-NAV-CONTEXT-V1`

正文源文件：

`docs/AIONE_GLOBAL_NAVIGATION_CONTEXT_AND_SIDEBAR_LOGIC_V1.0.md`

运行时知识对象：

`js/data/help-center-articles.js`

## 第2阶段边界

本轮没有修改现有Sidebar菜单生成。下一阶段才执行：

- 事业工作台页：显示当前事业的工作台导航与当前工作台局部节点。
- 全局之家/中心页：不再显示无关事业工作台；改为当前模块本地导航。
- 当前事业切换只保留在Header；Sidebar不重复事业切换控件。
- Sidebar/Aside只锁定规则与视觉，不锁死所有业务内容。

## 人工验收重点

1. Header增加知识之家后，第一行在常用桌面宽度下仍无明显拥挤或错位。
2. 点击知识之家进入知识总览。
3. 点击右上角帮助图标进入知识之家并自动筛选“帮助中心”。
4. 帮助中心可看到《AIONE全局导航与页面上下文逻辑说明》。
5. 点击“查看内容”可打开完整正文。
