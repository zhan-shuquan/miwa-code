# AIONE V1.0.24｜测样工作台共享内测骨架

日期：2026-08-21  
状态：CANDIDATE / 可运行验证版

## 本轮目标

不进行深度视觉优化，优先把“选品 → 测样”整理为可以继续接真实多人共享数据的稳定页面骨架。

## 本轮完成

- `02 测样工作台` 默认入口调整为 `测样概览`。
- 新增 `测样概览`：说明工作台定位、为什么需要测样、上下游业务关系、标准流程、XP / ST / T 对象关系、人 / AIONE / AI 责任。
- 新增 `测样任务`：以测样业务视角读取统一任务数据。
- 新增 `待测样商品`：保留 V1.0.23 原有商品机会 → 测样执行入口，不丢旧业务能力。
- 旧测样执行页继续复用商品机会详情中的完整恢复能力，不重写、不做深度美化。
- 现有 `collaboration-store` 任务结构增加工作台、业务对象、路由、去重键等字段。
- 测样任务与“今日工作”读取同一任务记录；任务可以从两个入口打开同一测样执行页面。
- 测样执行完成时，嵌入页向平台外壳发送完成事件，同一测样任务自动标记完成。
- 当前预演任务仍使用浏览器 localStorage；真正跨账号实时共享尚未完成，下一阶段应接 Cloud SQL / Tasks API。

## 页面职责

- 测样概览：理解工作。
- 测样任务：找到工作。
- 待测样商品：从商品机会建立测样任务。
- 测样执行页：完成具体测样。
- 今日工作：按当前人员查看跨工作台任务；与测样任务不是第二套任务数据。

## 下一阶段

1. 建立正式 `tasks` 数据表和 API。
2. 建立 `sample_runs / sample_results`（名称待最终锁定）真实业务对象。
3. 将 XP → ST → T 关系写入 Cloud SQL。
4. 使用两个真实成员账号交叉测试“同一任务、同一状态、同一测样结果”。
5. 多人闭环通过后，再决定页面与字段的进一步优化。
