# AIONE V1.9.23｜美和之家数字出版型空间 Candidate

## 1. 本轮目标

在不改变已锁定 Global Shell 的前提下，把“美和之家”建设成第一个成熟的内容展示型空间母版：

- 内部员工可快速理解美和集团；
- Sidebar 使用两级树形目录；
- Main 采用集团宣传册/数字出版式布局，而不是业务工作台布局；
- 内容、企业资料、PDF和未来美和AI共用同一内容定义；
- 9月正式业务启用优先，不把视觉微调和PPT自动生成放进当前主线。

## 2. 锁定定位

**美和之家**

> 美和集团内部的集团认知、战略方向、事业版图和组织发展的统一入口。

**美和概览**

> 一页理解美和集团的身份、理念、经营体系、事业版图、发展方向与成长历程。

## 4. Main V1

美和概览采用七段式集团叙事：

1. 集团封面
2. 从真实经营出发
3. 理念与文化
4. 美和原创AI经营架构
5. 事业版图
6. 发展路线
7. 发展历程

详细页按数据定义切换为：目录型、阅读型、事实型、架构型、路线型、事业版图型、品牌型、企业形象型、历史型、企业资料型。

## 5. PDF / 出版

- 网页和PDF共用内容，不共用Global Shell；
- `window.print()`进入A4出版模式；
- 打印时隐藏Header、Sidebar、Aside、Footer与操作按钮；
- 内容章节避免被无意义切断；
- 正式高分辨率Logo与架构图后续替换当前预览资产。

## 6. 企业资料

当前先建立资料索引、版本、权限和入口，不伪造尚未接入的文件URL。

PPT自动生成不进入V1.9.23主线。

## 7. 美和AI长期接口

后续美和AI默认按以下原则读取集团内容：

1. 权限允许；
2. 状态优先正式锁定；
3. 版本优先当前最新版；
4. 回答可返回原始来源和文件入口；
5. 对外资料仍需人类确认。
