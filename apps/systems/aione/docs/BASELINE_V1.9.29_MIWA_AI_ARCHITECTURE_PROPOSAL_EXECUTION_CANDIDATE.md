# AIONE V1.9.29｜AI总架构命名与Proposal执行候选基线

## 1. 正式主名称

本版本锁定两个长期主名称：

- **美和集团AI经营总架构**：回答“美和如何经营，并如何形成经营闭环”。
- **美和集团AI执行总架构**：回答“经营目标由谁、通过什么军团与AI协同机制转化为执行结果”。

“美和原创”“现代企业”“军团”等作为副标题、属性和方法表达，不再叠加进主名称。

## 2. 版本与历史名称

- 原《美和集团现代企业军团总架构》正式归入 **美和集团AI执行总架构**。
- Google Drive原件保持同一File ID，仅更名为 `00_美和集团AI执行总架构_V0.1.pptx`。
- 原名称继续作为历史别名，可被美和AI检索命中。
- **美和集团AI经营总架构**当前AIONE结构继续作为验证中的经营母架构；用户已确认存在新版原件，但当前尚未找到/绑定，因此不得用旧“基石版”冒充当前正式原件。

## 3. V1.9.29执行链

本版本把已有“分析能力”和“创建工作事项Proposal能力”正式衔接：

`当前页面真实上下文 → 美和AI分析 → 编号优化清单 → 用户选择条目 → 多个独立Proposal → 人工逐项确认 → 工作之家工作事项 → 后续结果/证据`

典型指令：

- `形成优化清单`
- `把第1、3、5项安排下去`

系统必须把第1、3、5项分别转换为独立的待确认工作事项，不强制合并。

## 4. 安全边界

- AI可以读取、分析、形成建议和Proposal。
- **AI不得自动写入工作事项。**
- 每个Proposal必须由有权限的人类负责人点击“确认执行”。
- 工作事项写入时继承来源页面、路由和关联对象，保持可追溯。
- 删除、外发、正式规则变更等高风险动作本版本不开放。

## 5. 当前状态

状态：**验证中 / Candidate**

通过生产真实验收后再升级为稳定基线。
