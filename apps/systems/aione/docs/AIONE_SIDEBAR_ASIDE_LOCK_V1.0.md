# AIONE Sidebar / Aside 正式锁定标准 V1.0

- 状态：正式锁定
- 生效日期：2026-08-24
- 适用范围：美和AIONE一体化工作平台全局Shell
- 原则：锁定区域职责、母版和生成规则，不锁死具体业务内容。

## 1. Sidebar｜当前空间的导航与启动区

Sidebar不承担全局导航。全平台统一视觉、宽度、树形/手风琴交互、缩进、高亮、展开/收起、滚动与组件规则；具体内容根据当前事业、之家、中心、工具、系统和页面上下文动态生成。

### 上部 Navigation Area｜约80%—90%

- 采用树形/手风琴式导航。
- 一级对象可展开/收起，二级节点缩进，当前项高亮。
- 业务型Sidebar只自动展开当前工作台/当前一级对象，其他保持收起。
- 原则上两层以内；极少数场景允许三级；禁止无限菜单树。
- 业务型、内容展示型、应用工具型、系统型共用同一母组件，只更换内容、图标和少量行为。

### 下部 Quick Actions｜约10%—20%

- 只放当前上下文0—3个高频启动动作，最多4个。
- 允许新建、批量导入、上传、发起流程等启动动作。
- 无高价值动作时不显示。
- 不承担第二套导航、任务中心、通知、风险、AI、完整表单或系统设置。

### Sidebar明确排除

- 跨事业全局能力由Header承担。
- 详情、编辑、单对象、动作页、复杂表单、分析报告等通过Main内部路由处理。
- 不再在Sidebar内维护独立事业切换器。

## 2. Aside｜当前上下文辅助区

Aside不承担导航、主要操作、任务中心、第二Main或AI核心功能。它只在当前页面/当前业务对象确有辅助价值时出现。

优先内容：

1. 当前对象/上下文摘要；
2. 关键状态；
3. 异常与风险；
4. 关联信息；
5. 必要场景说明或帮助。

允许状态：

- hidden：无辅助价值；
- light：仅少量摘要/提示；
- standard：上下文 + 少量高价值辅助卡片。

不要求所有页面常显或填满。

## 3. AI正式从左右边栏独立

AI是AIONE的系统心脏/全局智能能力层，不隶属于Header、Sidebar、Main、Aside、Footer任何单一区域。

废止AI秘书常驻Aside、右栏AI聊天、Aside固定问AI等旧设计。前端AI交互后续按已确认方向独立建设：美和AI快捷层 → AI工作区 → AI办公室。

## 4. 变更纪律

本标准生效后，与之冲突的旧Sidebar/Aside文档、测试、页面母版和代码均只作为历史记录，不得继续作为新开发依据。如需修改本标准，必须记录原内容、新内容、原因、影响范围和生效状态。
