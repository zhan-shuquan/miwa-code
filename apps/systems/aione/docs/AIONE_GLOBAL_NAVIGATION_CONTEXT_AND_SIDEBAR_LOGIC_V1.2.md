# AIONE全局导航与页面上下文逻辑说明 V1.2

- 文档ID：`KNOW-AIONE-NAV-CONTEXT-V1`
- 归属：知识之家 → 帮助中心
- 状态：正式锁定（Header结构与交互基线）
- 生效日期：2026-08-24
- 适用系统：美和AIONE一体化工作平台

## 1. Header的定位

Header不是普通导航条，而是AIONE的“头脑”：负责建立全局认知、身份、事业、工作、时间、核心对象空间和快捷调度。Header形成的上下文通过系统路由、配置和事件传递到Sidebar、Main、Aside等区域。

核心原则：**头脑越发达，前台操作越简单。**

## 2. H1｜全局上下文 + 核心之家

H1首先锁定工作上下文链：

**AIONE → 当前事业 → 当前用户 → 工作之家 → 美和日历**

底层语义：**公司 → 事业 → 用户（使用者） → 工作 → 时间**。

这五项为固定上下文核心，不因后续新增之家、应用或工具而改变顺序。

核心之家顺序锁定为：

**人才之家 → AI之家 ｜ 客户之家 → 供应商之家 ｜ 分类之家 → 商品之家 → 店铺之家 ｜ 分析之家 → 知识之家**

稳定关系：
- 人才之家 → AI之家：人才管AI，人类负责人承担最终责任。
- 客户之家 → 供应商之家：分别对应价值输出端与资源输入端。
- 分类之家 → 商品之家 → 店铺之家：分类定义归属，商品承载经营对象，店铺承载销售触点。

H1的核心之家区采用横向导航轨道。宽度足够时不显示左右控件；发生溢出时自动显示左右浏览按钮。未来扩展之家进入“更多”，无真实扩展内容时不显示空按钮。

H1右侧全局工具：**搜索 → 通知 → 帮助 → 设置**。帮助实际归属为“知识之家 → 帮助中心”。

## 3. H2｜快捷入口

H2的唯一任务：**让当前用户一步到达高频应用、工具、店铺后台或网站。**

前台不显示“共享资源”、“店铺之家”、“应用之家”等后台管理概念。快捷入口直接展示真实入口，各组只用细分隔符区分。

H2支持：
- 根据后台定性字段自动分组与排序。
- `quickAccess = true` 表示进入快捷入口体系。
- `headerHidden = true` 表示保留入口数据，但不显示在Header第2行。
- `quickGroup` 只负责分组、排序和插入分隔符，不显示分组标题。
- `sortOrder` 控制同组顺序。
- 宽度超出时自动显示左右滑动/浏览控件，不换行。

H2末端固定一个简洁的 **图标 + “更多”** 入口。“更多”进入“快捷入口”二级页，用于查看、说明、打开、隐藏和后续调整更多入口。

## 4. 共享资源｜仅内部管理名称

“共享资源”保留为AIONE底层资源注册、管理和配置概念，不作为Header第1行或第2行的前台名称。

共享资源可统一登记：**应用 / 工具 / 知识 / 代码 / 数据 / 模板 / 连接 / 服务 / 其他**。

“内部 / 外部”是后台属性，用于责任、安全、连接和维护判断；不强制在前台快捷入口页中展示。

## 5. 店铺之家与店铺快捷入口

店铺之家是H1一级长期对象空间，负责店铺资料、账号、平台连接、负责人、经营状态与商品映射。

幸せ屋、PrimeLife、永井GD等是H2快捷入口。“店铺之家”和“店铺后台快捷入口”不重复：前者管对象，后者负责一步到达。

## 6. H3｜美和精神与方法

H3继续承载：美和精神、核心准则、一体化→标准化→流程化→自动化、三大基石、三大属性。它不是普通业务导航，而是AIONE长期判断原则的持续可见层。

## 7. H4｜当前环境感知

H4锁定为三区：

**今日印象 ｜ 重要日程 ｜ 重要通知**

- 今日印象：地点、日期、星期、时间、农历等轻量环境信息。
- 重要日程：仅显示当前最值得注意的日程摘要，完整时间管理进入美和日历。
- 重要通知：仅显示当前重要提醒摘要，完整通知进入通知中心。

## 8. Header与其他区域的神经关系

- Header：认知、判断、方向与调度。
- Sidebar：根据Header已建立的事业、模块、页面类型和当前上下文生成局部业务路径。
- Main：处理当前主要工作。
- Aside：提供上下文辅助、风险、帮助与AI支持。
- Footer：低干扰提供系统可信度、环境、版本和生态连接。

## 9. 最终锁定表达

H1：**AIONE → 当前事业 → 当前用户 → 工作之家 → 美和日历 ｜ 人才之家 → AI之家 ｜ 客户之家 → 供应商之家 ｜ 分类之家 → 商品之家 → 店铺之家 ｜ 分析之家 → 知识之家 ｜ 搜索 / 通知 / 帮助 / 设置**。

H2：**快捷入口 → 自动分组和分隔 → 宽度不足时左右滑动 → 图标 + 更多**。

H3：**美和精神与方法原则**。
