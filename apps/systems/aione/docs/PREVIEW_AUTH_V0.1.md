## 安全边界

本地身份模拟不提供真实认证与数据安全边界，不得直接用于公网生产环境。
正式Preview部署时必须替换为Google OIDC/受控登录，并由服务端完成：

1. 登录白名单验证；
2. person_id / admin_identity_id 映射；
3. 权限模板与数据范围加载；
4. API与数据查询授权；
5. 登录、拒绝、权限变化和关键操作日志；
6. 会话失效与退出。

前端隐藏入口只能改善体验，不能替代服务端权限验证。

## 本地验证方式

启动HTTP服务器后打开根目录：

```text
python -m http.server 8080
```

浏览器访问：

```text
http://localhost:8080
```

首次进入显示AIONE Preview身份选择页。选择不同成员后验证Header身份和可见入口；右下角“切换身份”可清除当前预演会话并重新选择。
