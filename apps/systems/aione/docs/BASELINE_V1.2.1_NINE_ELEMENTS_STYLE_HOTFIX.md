# AIONE V1.2.1｜美和9要素组件样式修复基线

## 原因
V1.2.0 已经将「美和9要素」抽成唯一 JS 组件，但共享 CSS 中遗漏了该组件的视觉样式，导致组件被正确调用后仍以浏览器原生 HTML 样式显示。

## 修复
- 在 `css/components/level2-components.css` 中补齐唯一 `miwa-nine-elements` 组件样式。
- 恢复二级页面标准卡片、标题/副标题、`9 / 9` 状态、九要素等宽布局。
- 移动端/窄屏使用横向滚动，避免破坏页面高度。
- 主 CSS 增加版本查询参数，避免本地浏览器继续缓存旧样式。
- 验证脚本新增 CSS 存在性断言，防止以后出现“组件逻辑存在但样式缺失”的回归。

## 原则
这次只修复统一组件，不在客户之家、商品之家、通知页等单页分别打补丁。所有引用 `data-miwa-nine-elements` 的页面同步生效。
