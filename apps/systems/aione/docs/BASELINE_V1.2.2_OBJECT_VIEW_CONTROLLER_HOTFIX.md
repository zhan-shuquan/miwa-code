# AIONE V1.2.2｜对象卡片/列表统一视图组件热修复基线

## 目的
修复V1.2.x中“业务页面生成代码”与“标准组件调用”混用的问题。

## 核心调整
- 新增唯一 `js/components/object-view-controller.js`。
- 业务母版页面与选品工作台共同调用该组件。
- 组件工程负责卡片/列表的互斥显示、按钮状态与可访问状态。
- 页面工程继续负责真实业务数据与渲染内容，不自行实现第二套视图切换逻辑。
- 通用对象卡片/列表增加 `[hidden]` 强制隐藏规则，避免 author CSS 覆盖 HTML hidden 状态。
- 选品商品机会对象区增加显示防御，防止旧CSS或缓存导致卡片/列表区域不显示。

## 边界
本热修不改变选品流程、商品机会数据结构、数据库/API、成本/定价逻辑，也不重新设计选品卡片内容。
