# AIONE V1.9.24｜美和之家真实内容接入 Candidate

## 1. 本轮目标

V1.9.24不再扩展“美和之家”目录，而是在V1.9.23已经确认的空间结构内，把美和过去已经形成的真实理念、经营架构、事业方向和集团核心资料逐步接入AIONE。

优先级继续保持：

> 真实内容 / 业务逻辑 / 结构 / 使用体验 > 微小视觉精修 > PPT自动生成

## 2. 本轮真实内容范围

### 理念与文化

- 美和灵魂
- 美和准则
- 美和传承

这些页面当前接入的是已经在项目中持续形成并被使用的核心表达。后续如存在更完整正式原文，只替换内容源，不改变页面归属和母版。

### 经营与战略

经营架构页同时说明两层：

1. **美和原创AI经营架构｜母架构**：433、经营主线、操作闭环/业务闭环/经营闭环；
2. **现代企业军团｜执行体系**：作为母架构之下的集团级执行体系，不替代母架构。

现代企业军团当前保持V0.1“构想/验证中”状态，不因为进入AIONE就自动升级为正式锁定。

### 事业与治理

- 美和跨境、美和批发继续作为当前核心现实事业；
- 其他既有事业方向保留位置，实际状态继续按真实经营确认；
- 集团组织与治理页面只解释结构与责任，不替代人才之家、知识之家或未来正式治理制度。

## 4. 一份内容，多处调用

V1.9.24开始把集团内容按照以下方式组织：

- 页面：员工快速阅读、理解与内部路由；
- 企业资料：管理正式源文件、版本和权限；
- PDF：通过出版模式输出；
- 美和AI：下一阶段读取统一页面与资料索引；
- 官网：未来只调用明确允许公开的正式内容。

## 5. 美和AI准备

`getMiwaCompanySearchRecords()` 当前输出页面记录和企业资料记录，至少包含：

- title
- subtitle
- status
- visibility
- version
- current
- searchable text
- page route（适用时）

V1.9.25目标不是先做复杂Agent，而是先让美和AI做到：

1. 找得到；
2. 优先返回当前正式/最新内容；
3. 能说明来源；
4. 权限不允许时不返回；
5. 原件未绑定时不伪装成可下载。

## 6. 当前明确不做

- 不重新设计美和Logo；
- 不把视觉微调升级为当前主线；
- 不虚构会社概要法定字段；
- 不把V0.1验证资料改成“正式锁定”；
- 不在本轮开发自动PPT；
- 不为了资料页好看而复制出第二套内容。
