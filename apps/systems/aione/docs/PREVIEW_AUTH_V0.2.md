# AIONE Preview 身份与工作归属 V0.2

## 当前目标
内测阶段不是用权限把人隔离，而是让所有成员完整理解AIONE，并把真实工作归属到正确的人。

**原则：全开放、强归属、重记录、后收权。**

- 所有内测成员：全部业务平台可见、全部内测能力可体验。
- person_id：负责回答“谁在做什么”。
- workAssignment：记录主要责任域/店铺/业务方向，但不限制可见范围。
- Preview Activity：当前先用浏览器localStorage验证活动记录结构。
- 后续：任务、完成量、结果、异常、AI使用、协作、质量、考核统一绑定person_id。
- 正式启动前：再根据真实需要增加细粒度访问/数据/操作/审批权限。
