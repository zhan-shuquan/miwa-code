# AIONE 内容展示型页面母版 V1.0

状态：正式锁定（平台级内容展示规范）  
对应工程版本：V1.9.31.2  
日期：2026-08-26

## 1. 定位

AIONE 页面分为两类：

1. **内容展示型 Main**：以“容易阅读、理解、记忆、分享、出版”为第一目标。适用于美和之家、事业之家、理念、战略、架构、知识说明、工作台概览等。
2. **业务执行型 Main**：以“高效操作、状态推进、数据录入、列表筛选、流程执行”为第一目标。订单、采购、库存、客服、任务等继续使用企业 SaaS 布局，不强制套用本母版。

本母版只规范内容展示型页面。

## 2. 核心视觉原则

- 参考《美和集团AI执行总架构 V0.1》的出版式阅读语言，而不是传统后台卡片堆叠。
- 默认按 **A4 横向 297:210** 的书页比例组织一页内容。
- 一个页面只讲清一个核心主题；标题强、说明短、内容结构化、允许大量留白。
- 封面必须大气，正文以章节号、大标题、短说明、3–5个并列内容块、结论条、页脚组成。
- 内容少时不为了“填满”而补文字；详细信息进入下一级页面、相关资料或美和AI。

## 3. 品牌颜色

企业级内容页面只使用美和品牌体系：

- 美和绿 `#176B4D`：主色、标题、主线、主要交互。
- 深绿 `#0D4937`：封面、深层标题。
- 中绿 `#5E9B82` / 浅绿 `#E8F2ED`：辅助层级。
- 美和红 `#C83A32`：少量重点、页码、警示或品牌强调；原则上不超过5%。

不得使用蓝、紫、金、橙作为内容母版的常规主题色。

## 4. Global Shell 宽度

- Sidebar：继续使用平台固定宽度 `232px`，内容页不得自行改变。
- Aside：内容页采用平衡宽度：
  - light：`260px`
  - standard：`292px`
  - hidden：`0`
- Main：内容模式缩小外部 padding，让横向A4书页获得更完整的可视宽度。

原则：**Sidebar职责稳定；Aside保持轻量；Main优先保证书页比例和阅读空间。**

## 5. 书页结构

推荐结构：

1. 顶部绿色细线 / 章节编号 / 页码
2. 核心大标题
3. 一句解释
4. 中部结构化内容（3–5栏 / 对照 / 流程 / 架构）
5. 大量留白
6. 底部结论条
7. Footer：资料名称 / 版本 / MIWA / 页码

“三栏、四栏、五栏”不是不同母版，只是同一书页语言下不同内容数量。

## 6. 屏幕与出版同源

- 屏幕端：保持A4横向比例优先，允许点击、路由、美和AI和资料关联。
- PDF / 打印：隐藏Header、Sidebar、Aside、AI及交互按钮，只输出书页本体。
- `导出PDF` 按钮调用浏览器打印能力，使用 A4 landscape 版式；正式保存PDF时关闭浏览器默认页眉页脚可获得最干净成品。
- 未来如引入服务器端PDF Renderer，应继续复用同一DOM与CSS，不另维护第二份内容。

## 7. 移动端

- 移动端必须允许正常上下滑动。
- 能保持书页比例时保持；内容超出时页面允许自然增长，不裁掉正文。
- 不为了维持固定比例而把文字缩小到不可阅读。
- 手机端仍体现“书页”边界、章节与留白，而不是退化成普通卡片列表。

## 8. 工程组件

- CSS：`css/components/miwa-publication-master.css`
- JS：`js/components/miwa-publication-master.js`
- 页面进入内容模式时调用 `setPublicationPageMode(true)`。
- 顶部工具栏通过 `publicationToolbar()` 生成。
- 打印/PDF动作通过 `bindPublicationActions()` 统一绑定。
- 书页容器使用 `.miwa-publication-book`。
- 独立页使用 `.miwa-publication-page`。

## 9. 当前首个真实应用

`事业之家 / business-home` 作为本母版第一个真实验证页面。

后续美和之家、人才之家、AI之家、客户之家、供应商之家、商品之家概览、知识之家等内容页，应优先复用该母版；业务执行页除外。
