# AIONE 全局外壳 V1.0.6 Core Ready

## 本次锁定结论

全局头部的结构、顺序、名称、内部地址和多端表达可作为后续业务开发基线。外部店铺与工具地址未确认前继续为空，不创建假链接。

## 可内测的四项核心能力

### 1. Google 用户登录与退出

- 只有已登记 Google 账号可以登录。
- 所有已登记成员默认可见全部工作台，不按岗位隐藏入口。
- Header 外层统一显示 Google 头像、全名和职级；未确定职级时自动不显示。
- 用户卡片显示主要岗位、主要职责、主要项目、所属主体和登录账号。
- 退出登录只保留在用户卡片内，不再出现右下角重复入口。

当前属于前端内测身份识别。正式上线前需由后端验证 Google ID Token，并将成员、会话和审计记录保存到正式数据库。

### 2. 今日工作

- 任意成员都可以向任意成员布置任务，不设置管理权限门槛。
- 支持“与我有关 / 待我处理 / 全部公开”筛选。
- 支持标记完成与恢复待办。
- “建议与创新”面向全体成员开放，并与任务共用今日工作入口。
- Header 今日工作数字读取当前登录人的待处理任务数。

### 3. 美和日历

- 提供月历、今天、上月、下月、日期选择和当日安排。
- 可以新增公司、会议、工作或个人日程。
- 今日工作中设置完成日期的未完成任务会自动显示在对应日期。
- Google Calendar 双向同步只保留稳定接口位置，尚未假装接通。

### 4. 跨境日本业务

Web 左侧固定显示：选品、测样、采购、视觉设计、上架发布、运营推广、订单与库存、客服与售后，共 8 个工作台。手机和平板通过底部“跨境业务”打开相同的 8 项清单。

选品和测样连接现有真实页面；其他工作台保留稳定内部路由和空承接页，后续按业务优先顺序填充内容。

## 当前数据边界

今日工作与美和日历当前使用浏览器 `localStorage`，用于验证真实新增、保存、完成、任务映射日历和身份归属。它不会在不同电脑或浏览器之间自动同步。

正式数据库接入时保持现有页面和路由不变，只需将 `js/data/collaboration-store.js` 的本地实现替换为 API 数据服务。

## 系统启用前必须完成

- 确定美和统一图标体系后，通过 `js/config/semantic-icons.js` 一次替换全平台通用图标，不逐页改图标。
- 根据最终准确资料统一补齐店铺与工具外部链接。
- 启用后端 Google Token 验证、正式成员会话和登录审计。
- 将任务、建议与创新、公司日程接入正式数据库，完成多人和多端实时同步。
- 根据中国与日本团队的实际使用规则，决定并测试 Google Calendar 同步范围。
