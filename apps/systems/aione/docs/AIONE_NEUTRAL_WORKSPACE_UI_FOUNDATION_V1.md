# AIONE Neutral Workspace UI Foundation｜V1.0

状态：正式锁定  
日期：2026-08-30  
适用范围：美和AIONE一体化工作平台

## 1. 核心原则

AIONE 工作型页面采用 Google Workspace 式中性色工作界面。

- 工作页面重阅读，展示页面重品牌。
- 品牌色负责识别和动作，中性色负责工作和阅读。
- 美和绿只做“点”和关键动作，不做大面积阅读背景。
- 美和红只表达风险、异常、失败、超期、阻断和危险操作。

## 2. 工作型页面

以下页面默认执行 Neutral First：

- Main 工作区
- 工作台概览
- 列表页
- 对象页
- 配置页
- 表格、卡片、筛选、Tabs、普通信息区

默认视觉：

- 页面：浅灰／暖白
- Surface：白色
- 边框：浅灰
- 主文字：深灰黑
- 次要文字：中灰
- Hover：极浅灰
- 阴影：仅允许轻量工作区阴影

## 3. 美和绿 #176B4D 的正式职责

允许用于：

1. 主按钮
2. 关键操作
3. 导航激活
4. 成功／正常／已完成状态
5. 少量视觉锚点：
   - 当前项 2px 下划线
   - 小型图标 active 状态
   - 标题前 2–3px 细线
   - Focus ring
   - Checkbox / Radio / Toggle 选中状态
   - 正常进度条
   - 时间线当前节点
   - 少量核心 KPI
   - 图表主系列

禁止作为：

- Main 大面积背景
- 普通卡片背景
- 普通表格整行背景
- 普通 Tabs 胶囊底色
- 所有 KPI 的默认颜色
- 所有图标的默认颜色
- 无业务语义的装饰色

## 4. 美和红 #C83A32 的正式职责

仅用于：

- Error
- Risk
- Overdue
- Blocked
- Failed
- Destructive action
- 严重提醒

不得因为“想强调”而使用红色。

## 5. 横向 Tabs

同一对象、同一页面结构，仅类型／来源／互动维度不同的内容，使用统一 `AioneTabs`。

默认风格：

- 白／透明背景
- 深灰文字
- Hover 轻灰
- 当前项加粗
- 当前项下方 2px 美和绿细线
- 禁止绿色胶囊作为默认 Tabs

业务结构不同、页面结构不同、业务流程不同的内容，不应硬塞进 Tabs，应成为独立 Sidebar 页面。

## 6. 概览页

工作台本身可直接作为概览入口，不强制再建立“概览”目录。

概览页同样执行 Neutral First。只有以下展示型区域可以适度增加品牌色：

- 封面
- 封底
- 品牌边框
- 品牌识别区
- 汇报／演示型页面
- 对外展示页

## 7. 选品工作台当前锁定示例

Sidebar：

- 我的选品
- 我的互动
- 商品企划

工作台根页面本身即概览，不单列“概览”。

### 我的选品

横向视图：

`全部｜直发选品｜常规选品｜AI选品`

这些视图复用同一套商品机会／选品对象工作区，不复制数据结构和对象能力。

### 我的互动

横向视图：

`全部｜关注｜收藏｜点赞｜评论｜转发｜@我`

### 商品企划

商品企划不是选品类型。

- 选品：从已有商品机会中判断“选什么”。
- 商品企划：从需求出发定义“做什么”。

由于业务目标、对象和流程不同，商品企划保留独立页面／流程，不进入“我的选品”横向 Tabs。

## 8. 代码实现基线

Design Token：`css/foundation/tokens.css`

共享视觉基础：`css/components/aione-ui-foundation.css`

共享 Tabs：`js/components/aione-tabs.js`

组件登记：`js/components/component-registry.js`

总 CSS 入口：`css/miwa-system.css`

后续页面不得重新手写同类 Tabs、Card、Button、Status、KPI 的独立颜色体系。新增页面优先调用本基础层；确需例外时应记录原因和影响范围。
