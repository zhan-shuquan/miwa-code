# AIONE V1.9.29.1｜工作之家恢复候选基线

日期：2026-08-26
状态：Candidate / 待生产真实验收

## 1. 修复目标

恢复 Header「工作之家」的正确职责，避免其错误加载「事业之家」页面。

工作之家正式定位：

> 美和集团所有成员统一接收、查看和跟踪工作事项的全局工作入口。

事业之家回答“进入哪个事业”；工作之家回答“现在有什么工作、来源是什么、做到什么状态”。

## 2. 本轮结构修复

- `#/work` 使用独立 `pages/work-home/template.html`，不再复用事业之家静态模板。
- 工作之家Sidebar：工作概览 / 我的工作 / 待处理 / 进行中 / 待确认 / 已完成。
- 标准业务页面统一改用 `pages/business-template/template.html`，事业之家静态模板只服务事业之家，避免同类错配再次发生。

## 3. 正式数据来源

新增 `GET /api/v1/work-home`：

- 必须有已认证AIONE人员身份；
- 只返回当前人员负责或由当前人员创建的工作事项；
- 读取正式 `work_items` 数据库；
- 支持美和AI确认后的工作事项；
- 未确认AI Proposal不会进入工作之家。

## 4. AI Proposal追溯

美和AI确认创建的工作事项显示：

- 来源：美和AI；
- 来源页面/Route；
- Proposal ID；
- 状态、优先级、截止时间；
- 当前负责人。

## 5. 真实验收标准

在V1.9.29中只确认一张Proposal后：

1. 工作之家只出现该1条正式工作事项；
2. 另外未确认Proposal不出现；
3. 状态为待处理；
4. 来源显示美和AI；
5. 上下文可追溯到经营架构页面；
6. Proposal ID可追溯。

通过后，正式确认：

> 美和AI分析 → 优化清单 → Proposal → 人工确认 → 工作之家 V1闭环真实验证通过。
