# BASELINE V1.9.3｜Header核心之家 + 共享资源快捷层 Candidate

日期：2026-08-24

## 本版锁定

1. H1上下文顺序：公司 → 事业 → 用户 → 工作 → 时间。
2. H1核心之家：人才之家 → AI之家；客户之家 → 供应商之家；分类之家 → 商品之家；分析之家 → 知识之家。
3. 店铺之家、应用之家、共享之家不再作为Header一级导航。
4. H2仅承担高频共享资源快捷入口，不显示分组标题，只通过自动分组后的分隔符区分。
5. 共享资源产品形态统一为：应用、工具、知识、代码、数据、模板、连接、服务、其他。
6. 内部/外部作为资源属性，不拆成两套资源体系。
7. `headerHidden`允许资源保留在共享资源目录但隐藏Header快捷入口。
8. ERP作为内部应用登记在共享资源，同时进入H2高频入口；HR同样按应用登记，本版默认隐藏快捷入口，等待真实使用条件确认。
9. 新增供应商之家一级长期对象入口，并与客户之家相邻。
10. “全部资源”作为H2尾部统一入口，进入共享资源页面。
