# AIONE V1.9.31｜事业之家 Candidate

日期：2026-08-26

## 正式定位

事业之家：美和集团各事业的统一认知、进入、经营状态与发展管理入口。

边界：
- 事业之家回答“集团有哪些事业、为什么存在、处于什么阶段、我要进入哪里”。
- 工作之家回答“我现在有什么工作、做到什么状态”。
- 具体事业/工作台负责真实业务执行。
- 事业之家不是企业资料仓库，也不提前建设尚未启动事业的业务系统。

## 两级 Sidebar

- 事业概览
- 集团事业：美和跨境 / 美和批发 / 美和采购代理 / 美和物流 / 美和留学 / 美和不动产 / 美和商务咨询 / 美和品牌
- 事业管理：事业定位 / 事业负责人 / 事业阶段 / 事业目标 / 事业关系
- 事业发展：现有事业 / 培育事业 / 未来事业 / 事业里程碑
- 经营连接：进入事业 / 经营数据 / 工作事项 / 相关资料

## 当前事业事实

- 美和跨境：当前核心经营事业，AIONE第一真实业务实验场。
- 美和批发：第二核心现实业务，已有完整六段批发流程骨架。
- 美和采购代理：过去已有较多真实客户，面向日本客户提供中国寻源、报价、采购、验货、集货、国际发货、结算与售后；当前只在AIONE做事业介绍，不马上开发采购代理系统。待AIONE稳定后再评估独立客户网站/门户。
- 美和物流 / 留学 / 不动产 / 商务咨询 / 品牌：当前仅锁定事业方向，具体模式、负责人、目标和启动时间待正式确认。

## Main 设计

事业之家作为内容认知型页面，正式参考《美和集团AI执行总架构 V0.1》PPT的信息表达方式：强结论、章节编号、3—4模块卡片、关系板、流程、留白与出版感，同时保留AIONE企业级交互规范，并支持A4 PDF打印。

## AI 上下文

美和AI可读取事业之家正式内容，包括事业名称、阶段、真实业务基础、流程、系统是否已配置及当前建设边界；不得把培育/规划事业回答成已正式运行。
