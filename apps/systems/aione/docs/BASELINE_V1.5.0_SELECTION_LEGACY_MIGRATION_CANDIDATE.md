# AIONE V1.5.0｜选品成熟业务迁移候选基线

状态：**验证中（CANDIDATE）**

日期：2026-08-22

## 1. 本轮定位

V1.5.0 是第4阶段 `Legacy Migration｜成熟业务迁移工程`。

目标不是重新设计01选品工作台，而是验证已经形成的AIONE二级页面架构能否承载历史最成熟、业务逻辑最复杂的真实工作台。

正式迁移关系：

`Global Shell → Level-2 Empty Base → Standard Business Template → Shared Components → Selection Adapter → 既有选品数据/详情链路`

## 2. 明确保留，不重做的成熟业务

- 商品机会对象与既有预演数据源。
- 直发选品 / 常规选品 / 产品开发三种类型。
- 商品机会 → 数据录入 → 成本试算 → 智能定价 → 上架判断五段主流程。
- 测样仍为按需验证，不改成固定主流程节点。
- 每页12项的分页业务习惯。
- 新建商品机会与编辑既有商品机会继续进入原商品机会详情路由。
- 批量导入继续调用既有 `importPreviewOpportunities`，不建立第二份商品机会数据。
- 原成本、定价、测样、上架判断等详情业务逻辑不在本轮重写。

## 3. 本轮替换的页面基础设施

### 3.1 薄页面入口

`pages/selection-workbench/home.html` 仅保留标准业务母版入口，不再拥有旧选品页面结构。

### 3.2 Selection Adapter

新增：`js/data/selection-workbench-adapter.js`

职责：
- 读取既有商品机会数据；
- 将选品业务语义转换为标准组件需要的对象、类型、流程、指标、筛选与排序结构；
- 不复制商品机会业务事实。

### 3.3 共享 TypeRail

新增：`js/components/type-rail.js`

选品类型与其他标准业务页面共用同一类型组件。

### 3.4 共享 FlowComponent

共享流程组件支持：
- 节点Key；
- 节点数量；
- 当前节点；
- 点击筛选；
- 静态字符串流程的向后兼容。

选品只提供五段已确认流程定义，不拥有独立流程组件。

### 3.5 Universal Workspace

共享工作区本轮补齐：
- 搜索；
- 多条件筛选；
- 排序；
- 导入；
- 导出；
- 卡片/列表视图；
- 卡片3/4/6列；
- 重置；
- 可选分页；
- Loading / Empty / No Results / Error / Forbidden标准状态。

选品当前筛选维度：
- 选品类型；
- 状态；
- 负责人；
- 时间范围；
- 流程节点；
- 关键词。

### 3.6 Object Presenter

共享对象组件新增 `rich-media` 卡片表达，用于商品机会等有代表图、目标、事实、结果的业务对象。

卡片与列表仍读取同一商品机会数据，不建立双数据层。

### 3.7 美和9要素

继续调用唯一共享组件，固定顺序：

`目标｜人｜物｜事｜平台｜时间｜钱｜信息｜结果`

## 4. 活动运行时清理

旧选品工作台页面JS/HTML/CSS完整备份至：

`recovery/legacy-pages-v1.5/`

活动运行时：
- 不再使用旧 `selection-page-head` 页面骨架；
- 不再使用旧 `selection-card-grid` / `selection-list-view`；
- 不再由选品页面调用旧 `ObjectViewController`；
- `css/pages/selection-workbench.css` 仅保留批量导入这一选品特有能力的样式。

## 5. 共享组件同步增强

为保证选品不是“特殊兼容页”，本轮增强发生在共享组件层：
- TypeRail；
- FlowComponent；
- Universal Workspace；
- Object Presenter。

同时 `business-page-template.js` 已改为调用共享 TypeRail，避免选品独享新组件。

## 6. 本轮不处理

- 不修改选品业务字段定义。
- 不修改成本公式、定价逻辑、测样逻辑和上架判断规则。
- 不进入字段标准化/数据库Schema阶段。
- 不真正接入AI秘书GPT/Tool Layer。
- 不迁移测样、采购、设计、上架、运营、订单、库存、客服等其他历史工作台。
- 不讨论页面细节和业务内容重设计。

## 7. 正式锁定条件

只有同时满足以下两类验收，V1.5.0才可从“验证中”升级为正式迁移基线：

### 架构验收
- 选品根页真实调用唯一空母版与标准业务Recipe；
- 卡片、列表、类型、流程、指标、9要素来自共享组件；
- 活动运行时不存在选品独立母版复制；
- 卡片/列表同源且互斥；
- 3/4/6列、搜索、筛选、排序、分页可用。

### 业务回归验收
- 现有商品机会正常显示；
- 三类选品可用；
- 五段流程可用；
- 新建/编辑详情链路可用；
- 批量导入可用；
- 12条/页分页可用；
- 既有选品数据不丢失；
- 原详情流程中的成本、定价、测样、上架判断不受破坏。

正式锁定前必须完成Windows + Live Server人工浏览器验收。
