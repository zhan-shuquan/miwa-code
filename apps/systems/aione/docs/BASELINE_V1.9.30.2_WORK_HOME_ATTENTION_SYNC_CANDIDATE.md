# AIONE V1.9.30.2｜工作之家全局提醒实时同步 Candidate

日期：2026-08-26

## 目标

工作之家 Header 红色数字不再代表“全部历史/进行中工作总数”，而是明确代表：**当前需要我处理的工作数量**。

提醒范围：
- 待处理：当前用户为负责人。
- 待确认：当前用户为创建者/复核人。
- 超期：当前用户负责且未完成。
- 阻断/异常：当前用户相关且需要处理。

普通“进行中”但未超期的工作不进入 Header 红色数字；已完成工作永远不进入提醒。

## 同步机制

第一阶段采用低复杂度准实时方案，不引入 WebSocket：
1. Proposal 人工确认创建工作成功后，立即刷新。
2. 工作开始、提交完成、确认完成等状态变化后，立即刷新。
3. 浏览器窗口重新获得焦点时刷新。
4. 页面从后台重新变为可见时刷新。
5. 每 60 秒轻量轮询一次作为多人协作兜底。

## 数据原则

- 正式环境继续读取 `/api/v1/work-home`，不新增重复工作统计表。
- Badge 只是同一份 `work_items` 事实的动态计算结果。
- API 异常时本地 Preview 可回退 Collaboration Store，但正式数据失败不得冒充正式成功。
- 一项工作只计数一次，即使同时满足超期和其他提醒条件。

## 事件

- `aione:work-items-changed`：工作事实变化后触发。
- `aione:work-attention-updated`：重新计算提醒后发布。
- `window.AIONEWorkAttentionSync`：提供手动刷新、事件通知和当前快照。
