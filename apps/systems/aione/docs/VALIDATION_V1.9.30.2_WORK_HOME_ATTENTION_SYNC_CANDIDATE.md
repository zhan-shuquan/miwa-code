# V1.9.30.2｜工作之家全局提醒实时同步｜真实验收

## 必测场景

### 1. AI创建工作后立即出现
1. 在美和AI中生成创建工作 Proposal。
2. 点击「确认执行」。
3. 不刷新浏览器。
4. Header「工作之家」红色数字应在短时间内自动增加。

### 2. 开始执行后提醒减少
1. 打开一条本人待处理工作。
2. 点击「开始执行」。
3. 若该工作未超期且没有异常，Header红色数字应立即减少，不要求刷新。

### 3. 待确认提醒
由另一负责人提交需要创建者确认的结果后，创建者 Header 应计入该待确认工作。

### 4. 页面重新获得焦点
切到其他浏览器标签页后制造工作变化，再回 AIONE；Header 数字应自动重新同步。

### 5. 60秒兜底
多人操作下即使没有前端事件，保持 AIONE 页面可见，最长约 60 秒应自动同步。

## 语义验收

Header数字只代表“当前需要我处理”：待处理 + 待确认 + 超期/阻断（按工作ID去重）。
不包括普通进行中与已完成工作。
