# AIONE 商品之家 CURRENT V1.0

Status: CURRENT
Effective: 2026-09-03

## 核心原则
- 商品之家是统一 Product Context 业务域，不是孤立页面集合。
- Product / SKU 是正式核心对象；正式 Product 至少 1 个 SKU。
- Product ID: `MH0000001`; SKU ID: `MH0000001-01`。
- Product Context Header 固定顺序：商品图 → 当前业务对象编号 → 商品简称。
- 列表 / 卡片只是 View，不得削弱对象能力。
- 对象通用能力：编辑、负责人、状态、评论、@成员、关注、收藏、附件、时间线、操作记录、状态历史、关联对象、AI摘要/建议、更多操作、批量操作。
- 全局仅保留 美和AI + 商品之家AI秘书；不新增中心AI。
- 各中心参数就近放在本中心设置；是否建设统一设置中心以后再讨论。
- 各中心均应有导入 / 导出能力，属于中心级操作。
- 商品之家只保留一个之家级回收站，不为每个中心单独建垃圾箱。
- UI继续采用 Google / Material 风格：简洁、轻量、清晰、低干扰、常用动作外露、低频动作收起。

## 商品之家中心顺序
概览 → 选品中心 → 商品中心 → 设计中心 → 发布中心 → 成本中心 → 价格中心 → 利润中心 → 分类中心 → 品牌中心 → 属性中心 → 规格中心 → 编码中心 → 测样中心 → 采购中心 → 库存中心 → 运营中心 → 客服中心 → 回收站。

基础中心固定顺序：分类 → 品牌 → 属性 → 规格 → 编码。

## 商品中心
横向：全部商品 | SKU | 设置。

工具栏：＋新建商品 | 搜索 | 筛选 | 分组 | 排序 | 列表 | 卡片▼ | 导入 | 导出 | 批量操作。

卡片默认 3 列，可选 2 / 3 / 4 / 6；列表与卡片为两个一级按钮，卡片密度是卡片按钮的二级下拉。

完整商品资料属于 Product Object Workspace，不额外建立重复“商品资料”Tab。

## SKU Generator
SKU 不逐条手建。统一能力：

Product + Specification Template + Variant Values → SKU组合 / SKU ID / SKU名称 / SKU图片关联 / 原产国 / 初始状态。

入口：新建商品、1688导入、批量商品导入、AI商品识别、产品开发、已有Product新增规格。

原产国为 SKU 级标准事实。JAN / GTIN / EAN / UPC 属于唯一识别编码，由编码中心统一管理；条形码由编码生成。

## 成本 / 价格
沿用已讨论成熟的术语，不重新命名：
- 商品销售成本
- 基础交易成本
- 单件销售成本
- 建议售价
- 最低保本价
- 活动价
- 目标利润 / 目标毛利率 / 最低毛利率

成本中心输出成本事实；价格中心读取成本事实；利润中心结合真实销售与运营投入计算实际利润。

## 导航显示
当前默认全部中心显示。允许保留轻量 `中心显示 ▾` 入口，但不让个性化设置成为主流程。
