# AIONE数字出版｜双页书籍母版 V1.0

状态：验证中  
对应工程版本：V1.9.31.3  
日期：2026-08-26

## 1. 核心定义

**空间即书，目录即章，子目录即节，内容即页，奇数余页优先用于章总结。**

内容展示页与业务执行页必须分离：

- 内容展示页以“阅读、理解、记忆、培训、出版”为第一目标。
- 业务执行页继续使用SaaS表格、表单、状态、流程、按钮和数据操作布局。

## 2. 书籍结构

- 一个Header内容空间 = 一本书。
- 一级Sidebar目录 = 一章。
- 二级Sidebar目录 = 一节。
- 一节可由1页或若干页组成。
- 章节正文出现奇数余页时，右页优先生成“本章总结”，而不是机械填充无意义内容。
- 概览作为全书前置部分：封面、定位、阅读说明、全书目录；随后进入第01章。

## 3. 页面几何

- 默认书页：A4纵向比例 210:297。
- 桌面端：正文以P2/P3、P4/P5、P6/P7双页展开显示；中间保留轻量书脊/中缝视觉。
- 封面：单页居中，不与正文页并排。
- 移动端：单页纵向连续阅读，必须允许上下滑动；内容少时尽量保持书本比例，内容多时允许自然增长。
- PDF/打印：固定A4纵向，每个书页独立输出为一张纸，不允许响应式重排。

## 4. 信息布局规则

- A4纵向默认使用两列。
- 1项：单项重点版式。
- 2项：标准双列。
- 3项：优先2+1或1+2；只有内容短、完全同级时才使用三列。
- 4项：2×2。
- 5项：优先2+2+1、2+3或分页；不得为了填满空间缩小字号。
- 6项以上：根据阅读密度分页。
- 留白是正式出版设计的一部分，不以空间利用率为目标。

## 5. 封面系统

所有内容书册共享固定识别结构：

1. 美和集团 / MIWA GROUP身份。
2. 美和集团经营管理系列 / MIWA GROUP MANAGEMENT SERIES。
3. 主标题。
4. 英文识别标题。
5. 一句话定位。
6. 核心主张。
7. 专属图标/主题视觉槽位。
8. 美和AIONE一体化工作平台、书册名、版本、日期。

事业专属图标进入封面或事业章节视觉区，但不得重新设计正式图标。当前工程如果未包含正式事业图标资产，只保留标准槽位，并使用语义图标作为结构性回退；正式资产进入项目后仅更新映射，不改变母版布局。

## 6. 品牌色

- 主色：美和绿 #176B4D。
- 深绿：#0D4937。
- 强调/风险/少量重点：美和红 #C83A32。
- 内容背景以白色、暖白、中性色为主。
- 不使用蓝紫科技风替代企业主色。

## 7. 五区职责

- Header：全局入口。
- Sidebar：书籍目录 / 章节导航。
- Main：只展示“书”。打印、PDF等系统操作不得侵入Main。
- Aside：当前章节、资料状态、打印、导出PDF等上下文辅助。
- Footer：系统可信度、版本和生态连接。

## 8. 出版输出

屏幕版与出版版共享同一内容源：

- 屏幕：双页展开。
- 手机：单页连续阅读。
- PDF：A4纵向单页。
- 打印：可直接双面打印和装订。

打印时必须隐藏Header、Sidebar、Aside、美和AI、浮动工具和其他网页UI，只保留书页内容。

## 9. 当前第一验证对象

事业之家概览：

- P1 封面。
- P2 / P3 概览双页。
- P4 / P5 第01章正文双页。
- P6 / P7 第01章正文 + 本章总结双页。

第01章使用右页总结结束，作为“奇数余页优先用于章总结”的第一套真实验证。
