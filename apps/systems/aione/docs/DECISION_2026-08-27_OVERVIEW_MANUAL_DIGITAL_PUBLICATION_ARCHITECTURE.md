# 2026-08-27｜概览、数字手册与电子出版体系｜架构结论记录

状态：**平台级原则正式锁定；具体知识之家/电子出版中心页面与数据模型待后续开发。**

## 1. Sidebar = 当前空间章节目录

Sidebar不再按“技术功能清单”理解，而是当前之家、中心或工作台的章节目录。高价值用户意图可以拥有独立章节入口，即使技术上只是同一对象浏览器的不同Query。

## 2. 概览 = 当前空间认知入口

AIONE“概览”不等同于Dashboard。概览负责解释当前空间是什么、为什么存在、核心方法/流程、Sidebar各章节怎样使用、上下游关系及必要动态信息。

同类概览后续统一继承AIONE数字出版空母版；母版负责结构、排版与组件，具体业务内容按空间配置。后续如修改母版，应尽可能由空母版统一升级，而不是逐页重做。

## 3. 页面副标题 + 手册章节深链

每个正式Sidebar章节应有一句职责副标题，回答“什么时候应该使用这个页面”。

页面中的“查看手册”应直接定位到对应数字手册章节主标题，而不是统一回到手册封面。页面副标题负责马上理解，数字手册负责深入理解。

## 4. 帮助中心不重复保存一套手册

帮助中心长期定位为场景化知识访问服务：当用户遇到问题时，帮助其快速找到正确章节、规则、字段或SOP。正式知识和出版物只有一个来源，避免帮助中心重复维护内容。

## 5. 知识之家 → 电子出版中心

“电子出版中心”未来作为美和集团级数字出版平台，不从属于AIONE某一本电子书。当前结构方向：

- 概览：美和集团电子出版总览
- 01｜美和方法论
- 02｜系统出版物
  - 美和AIONE一体化工作平台
  - 未来美和留学系统
  - 未来美和独立站等独立系统/网站
- 03｜事业 / 专业出版物
- 出版管理

未来独立系统/网站可以通过统一接口/API把正式内容接入电子出版中心，不复制维护第二份知识。

## 6. 美和方法论是一级正式电子出版物

AIONE是美和方法论第一个真实业务实验场。经过真实业务验证、具备跨系统复用价值的方法，应从AIONE提炼进入《美和方法论》，再由AIONE、美和留学、美和独立站等系统引用。

原则：**先形成证据，再形成标准；系统应用方法，方法不从属于单一系统。**

## 7. 一本出版物只有一个真正的总封面与总封底

每一本独立电子出版物拥有唯一总封面和总封底。总封面/总封底可采用正式美和绿；篇章扉页、章节页逐级采用更浅的美和绿色阶，正文回归白/暖白。

在线整书中的各篇章使用“篇章扉页 / 篇章收束页”，不重复制造真正封面/封底。只有当某篇章被单独导出为独立手册时，系统才根据统一母版生成派生封面和派生封底。

## 8. 正式出版能力方向

后续电子出版体系应逐步支持：完整在线阅读、章节深链、版本管理、整本下载、选择篇章下载、独立分册导出、PDF/打印、Publication ID、二维码/条形码及出版贡献信息。

二维码应优先指向该出版物在线最新正式版本；条形码使用美和内部Publication ID，不伪造ISBN。

## 9. 本轮开发边界

V1.9.37只在工作之家落地“页面副标题 + 手册章节深链”等已经成熟的场景能力。

**本轮不开发：**知识之家整体结构、电子出版中心页面、集团Publication数据模型、人才之家关联。以上内容在对应模块正式开发时再进行完整业务/数据/页面设计。
