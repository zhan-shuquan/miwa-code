# AIONE 全局外壳 V1.0.5 Safe Rebuild

## 本候选的边界

- 从用户上传的原始代码重新建立独立候选，不覆盖原始目录。
- 保留现有选品工作台、商品机会详情、成本试算、智能定价、上架判断与测样业务代码。
- 只统一平台外层 Header、移动端入口、内部路由和业务页面装载方式。
- 外部店铺与工具链接继续由配置保存为空，待系统框架稳定后统一补齐。

## 已锁定的外层结构

- 第一行：公司识别区、用户登录区、今日工作、美和日历、分类之家、商品之家、AI之家、分析中心、共享之家、全局搜索、通知、帮助之家、设置。
- 第二行：店铺与工具两个独立分组；两个分组各有自己的“更多”。
- 第三行：美和精神、核心准则、三大基石、三大属性。
- 第四行：今日信息与重要通知；节气和星座只显示具体内容，不重复显示名称。
- 桌面、平板、手机共享同一语义、同一路由和同一图标映射。

## 内部路由原则

- 前台工作台名称不使用 01–08 编号。
- 已开发页面连接真实业务内容：选品工作台、测样工作台。
- 未开发页面保留稳定内部地址和空承接页，不伪造业务内容。
- 商品机会详情与测样详情以内嵌业务页方式进入统一外壳，避免二级页面出现另一套 Header。
- 所有入口集中登记在 `js/config/route-registry.js`。

## 权限与登录

- 仅保留 Google 登录入口，不提供本地身份按钮。
- 已加入名单的用户进入后默认可见全部工作台。
- 当前不按岗位隐藏工作台；未来如需限制，在设置层启用限制模式，不重建页面角色体系。

## 自动验证

在 AIONE 目录执行：

```bash
node tests/verify-global-shell.mjs
```

验证内容包括：内部路由完整性、八个工作台是否全部存在、工作台前台名称是否仍含编号、店铺与工具是否各有“更多”、选品和测样初始化是否接入，以及是否残留会阻断整页启动的旧校验。
