# V1.9.32｜工作之家 V2.0 第一次升级 Candidate

日期：2026-08-27  
状态：Candidate / 等待 Windows + Live Server 人工验收

## 已实施
- Sidebar统一为：工作概览、今日工作、我的工作、全部工作、等待与阻塞、待验收、工作记录。
- 旧状态路由保留兼容但从Sidebar隐藏；状态下沉Main筛选。
- 工作概览升级为出版物式活手册；正式加入“美和工作9问”。
- 今日工作第一版依据优先级、截止时间、状态、本人关系排序。
- 工作卡前台减法：关系、状态、优先级、为什么现在做、下一步、时间、一个处理入口。
- 工作详情加入“美和工作9问”，并继承既有执行证据、结果、人工验收、美和AI复盘闭环。
- 正式表达：看得到 ≠ 要处理 ≠ 能操作；透明 ≠ 推送。
- Work Item管“做什么”；Calendar Projection管“什么时候做”。本版不新建第二套日历任务。

## 本版边界
- 不修改 `work_items` Schema。
- 不把 `/api/v1/work-home` 改成全公司无边界读取。
- 不新增第二套任务表。
- 公司级透明读取、敏感事项、关注机制、产能排程和日历自动投影留到下一阶段。
- 因此“全部工作”在V1.9.32代表当前正式接口下全部可见工作。
