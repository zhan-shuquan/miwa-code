# 美和数字出版设计系统 V1.0

状态：V1.9.31.4 工程收口，待部署后视觉/PDF最终验收。

## 核心原则

- 空间即书，目录即章，子目录即节，内容即页，奇数余页优先用于章总结。
- 默认A4纵向；宽屏优先双页展开，但绝不为了维持双页牺牲字号、留白和阅读舒适度。
- 桌面首屏：正封面 + 封底；正文：P2+P3、P4+P5……连续展开。
- 中等桌面：优先保留双页可读性，Aside可收起；空间不足自动切单页。
- 手机：单页连续阅读。
- PDF/打印：真实A4纵向单页；正封面在前，封底在最后。
- Main只承载书籍内容；打印、导出PDF等操作归Aside或收起后的紧凑工具。
- 美和绿 #176B4D 为主色，美和红 #C83A32 只作识别、重点和少量强调。
- 封面、封底、章节、节、正文、章总结、页码、Footer和版本信息按出版物规则统一。
- 内容关系决定版式，不按数量机械排版。2列为常用结构，3列仅用于短且完全同级的内容；奇数可采用2+1、1+2、重点放大、分页或主动留白。
