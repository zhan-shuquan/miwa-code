# AIONE V1.9.27｜美和AI企业资料检索闭环 V1｜候选基线

状态：验证中
日期：2026-08-26

## 本版目标
让员工不需要记住Google Drive目录或文件名，直接向美和AI提出自然语言请求，由AIONE正式索引确定资料、版本、状态和交付入口。

## 核心链路
用户自然语言 → AIONE企业资料意图识别 → 正式Registry检索 → 权限过滤 → 当前版本判断 → 美和AI资料卡 → 查看内容 / 查看原件 / AIONE安全下载。

## V1确定性原则
- 最新版本、资料状态、Drive File ID不得由大模型猜测。
- 明确的企业资料请求优先进入AIONE Registry，不依赖模型是否在线。
- Live模型遇到更复杂的资料表达时，使用 `search_corporate_content` 工具取得正式证据。
- 内部资料必须存在已认证AIONE人员上下文才允许返回。
- 下载继续复用V1.9.26已真实验证的Shared Drive安全交付闭环。
