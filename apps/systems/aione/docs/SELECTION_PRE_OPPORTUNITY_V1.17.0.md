# AIONE 01选品工作台｜商品机会前置体系与入口调整 V1.17.0

状态：验证中 / CANDIDATE

## 本次业务边界

- 商品机会仍然是正式选品业务对象的起点。
- 商品机会之前属于发现、研究、责任、任务、方法与筛选体系。
- 选品概览负责统一“怎么想”。
- 选品任务负责统一“怎么做”。
- 选品工作台继续承载真实商品机会及正式流程。

## 工作台头部

只保留两个选品内部入口：

1. 选品概览
2. 选品任务

原头部「新建商品机会」「批量导入」「选品AI人才」退出。

## 业务类型

正式候选结构：

- 直发选品
- 常规选品
- 产品开发

AI选品不再作为业务类型。AI参与程度未来由执行主体、执行方式、字段来源及AI运行记录表达。

每个业务类型卡片提供：

- 新建商品机会
- 批量导入

两项操作自动继承当前业务类型。

## 暂不在本次锁定的内容

- 选品方向真实配置数据
- 深耕分类真实负责人数据
- 选品任务持久化数据结构
- 选品线索持久化数据结构
- AI全链路／AI经营循环结构
- 贡献奖、经营贡献账户等人才管理能力

上述内容继续验证，不提前包装为正式功能。
