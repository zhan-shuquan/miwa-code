# AIONE V1.0.14｜9工作台资产保全内测候选

状态：内测候选（CANDIDATE）
日期：2026-08-21

## 本次目标

1. 以 V1.0.11 已确认全局架构为主体，不改选品与测样既有页面内容。
2. 恢复并保持跨境 9 个独立一级工作台：选品、测样、采购、设计、上架、运营、订单、库存、客服。
3. 保全选品工作台全部既有下级页面与测样工作台既有页面、脚本和路由。
4. 仅移植已确认的“更多店铺 → 全部店铺正式总览页”能力。
5. 更多工具继续保持轻量入口，不扩张成独立复杂页面。

## 明确禁止

- 不将选品工作台与测样工作台合并为一个一级工作台。
- 不删除、重构或重命名已优化的选品/测样核心页面。
- 不把分析中心计入跨境业务工作台数量。

## 内测重点

- Header / Sidebar 全局架构与外部链接。
- 更多店铺进入“全部店铺”正式页面。
- 选品工作台及其下级页面可正常进入。
- 测样工作台保持独立入口并可正常进入。
- 其余 7 个业务工作台入口不受影响。
