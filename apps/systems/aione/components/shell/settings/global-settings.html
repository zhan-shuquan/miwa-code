设置

当前内测优先使用“集团默认”。正式扩展时按：集团默认 → 公司 → 事业 → 店铺/工作台 → 特殊对象逐级继承，仅差异项覆盖。

系统基础

统一平台语言、时区、对象分页与参数继承策略。

继承顺序：集团默认 → 公司 → 事业 → 店铺/工作台 → 特殊对象。当前共享内测以集团默认参数为主，避免过早制造复杂配置。

组织与权限

统一入口可见性、数据范围与敏感操作审计；内测阶段优先保持开放。

分类与字典

业务类型等高频字典统一维护；前三个作为重点类型展示，更多类型横向滑动。

业务母版与流程规则

统一二级页面结构，避免每开发一个页面重新设计。

金额与价格

保留现有成本、交易、运营、利润、物流与价格治理参数，并统一纳入系统参数中心。

直发配送参数

保留选品详情既有直发首重/续重参数，避免大升级破坏现有成本计算。

日本配送费标准

继续沿用当前配送档位并支持启停。

收入与支出

“钱”作为美和9要素之一，在业务发生时识别并汇入收入之家或支出之家。

店铺与应用

统一控制对象状态、链接检查和资料完整性；具体对象数据在对应之家维护。

导入与导出

对象管理工具栏固定保留搜索、筛选、导入、导出、卡片、列表；已有数据优先导入，不重复录入。

通知与任务

统一“新建业务对象 → 标准事件 → 通知/后续流程”的规则。

AI与自动化

AI有固定存在感，但不为了AI而增加按钮；优先在Aside和真实业务动作中提供帮助。

版本与审计

灵活配置不等于随意修改；锁定规则变更必须可追溯。
