# V1.14.0 数量单位语义专项审计

状态：通过
日期：2026-08-15
范围：商品机会记录详情页当前有效UI、Help、公式、参数追溯、校验提示、测样回写与推进判断文案。

## P0规则

> 物理属性用“单个”，经营核算用“单件”。

## 审计结果

- 旧经营口径“单个商品毛利 / 单个商品贡献利润 / 单个商品运营可控利润 / 单个商品全成本净利润”：当前有效页面中为 0。
- “目标/预计/实际单个商品…利润率”旧经营口径：当前有效页面中为 0。
- 当前“单个”仅保留于商品本体物理属性：单个预估毛重、实测单个毛重及其Help/计算说明。
- 当前成本与利润经营指标统一采用“单件”销售单位口径。
- 销售套装数量继续作为“一个销售单位包含多少商品本体”的独立字段。
- 历史CHANGELOG旧术语保留，仅作为版本演变证据，不代表当前标准。

## 多件套反例验证

示例：单个预估毛重150g，销售套装数量3个。

- 单个预估毛重：150g。
- 销售套装预估毛重：450g（未计额外包装时）。
- 单件固定成本、单件预计总成本、单件毛利、单件贡献利润等全部按一个完整销售单位/销售套装计算。
- 不允许把“单件利润”理解为单个商品本体利润。

## 冻结区域

Header、Sidebar、Aside、Footer及其他公共组件未修改。
