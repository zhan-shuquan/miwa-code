# AIONE 商品机会记录详情恢复预览 V0.4.1

状态：验证中。


## V0.4.1｜页面头部基础骨架合并

本版在 V0.4 完整业务恢复能力不变的前提下，把已确认的页面头部基础骨架正式合并进当前完整预览框架：

- 页面名称统一为「商品机会记录详情」。
- 页面头部采用「固定身份区 + 可选页面级操作区」。
- 固定身份区包含：标题图标、大号标题、简要说明、必要时帮助入口。
- 标题图标作为页面标题的视觉旗帜固定存在，本页使用内嵌 SVG 自定义图标。
- 返回入口与标题身份分离，改为轻量文字导航「← 返回商品机会列表」。
- 删除原头部中重复出现的「选品中 / 当前节点 / 资料完整度 / 正式货号」独立状态条；业务状态继续由流程导航和对应业务区表达。
- 页面级操作区作为标准结构保留，但只有出现真正页面级重要操作时才显示；当前详情页保持为空。
- 本次不修改成本试算、智能定价、测样、推进判断及全局 Header / Sidebar / Aside / Footer。


本版继续恢复两个关键业务节点：

- 02 测样工作台：恢复原 `SampleValidationRecord` 数据结构、样品申请/收样、五项快速质量检查、实测重量、证据、异常资料和结论校验。
- 推进判断：结合现行已锁定业务规则，将旧源码“继续/暂停/淘汰”语义校正为最终只保留“上架 / 不上架”；资料不足、需复测或利润不足时返回对应节点，不制造第三种最终结果。

## 重要边界

原 2026-08-07 源码中，测样的服务层、数据类型和测试已存在，但没有发现与其成熟度相同的完整前端测样页面。因此 V0.4 的“02测样工作台”界面属于**基于原真实字段与校验规则的恢复验证界面**，不是声称找回了不存在的旧UI。

推进判断保留旧源码的可追溯判断思想，但按当前锁定规则改为“上架 / 不上架”。

## 推荐测试顺序

1. 点击“载入原测试数据”完成成本试算与智能定价。
2. 点击“进入02测样工作台”。
3. 点击“载入恢复验证数据”，或手工填写。
4. 完成测样并回写01。
5. 检查实测重量是否触发成本/定价重新试算。
6. 回到01检查测样摘要与推进判断。
7. 测试“上架 / 不上架”最终结果。
