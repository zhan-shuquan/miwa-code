# V0.4.1 页面头部验证重点

1. 页面标题应显示「商品机会记录详情」。
2. 标题左侧固定显示自定义业务标题图标，返回入口不得与标题图标并列成两个主图标。
3. 返回入口应显示为轻量文字「← 返回商品机会列表」。
4. 标题下方只显示简要说明「记录商品机会从创建到最终推进判断的完整业务过程。」。
5. 问号帮助可展开 / 收起详细说明。
6. 原独立状态条不再显示；“选品中 / 当前节点 / 资料完整度 / 正式货号”等不得在页面头部重复堆叠。
7. 六节点业务流程导航继续正常显示，页面中部业务能力不应因头部调整而变化。
8. 页面级操作区结构应保留，但当前详情页没有真正页面级重要操作时不显示。
9. 成本试算、智能定价、测样与推进判断的既有验证规则保持不变。

# V0.4 验证重点

1. 成本/定价未完成时，测样入口应提示先完成前置节点。
2. 测样异常结论缺少问题资料或问题图时，不允许完成测样。
3. 启用实测单个毛重且数值变化时，当前记录的销售套装预估毛重和实时成本/智能定价应重新计算。
4. “需要重新取样 / 有条件合格”不应出现第三种最终经营结果，而应返回测样补充。
5. “合格，建议继续”且贡献利润率达到目标时，系统建议“上架”。
6. “不合格，建议淘汰”且证据完整时，系统建议“不上架”。
7. 最终按钮只有“上架 / 不上架”。
8. 完成“上架”后，页面只说明下游路由，不直接宣称已进入上架发布工作台。
