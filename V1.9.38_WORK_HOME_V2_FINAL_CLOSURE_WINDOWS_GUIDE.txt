V1.9.38｜工作之家 V2.0 最终收口｜Windows更新指南

【基线】
V1.9.37 WORK HOME STRUCTURE FINALIZATION CANDIDATE

【本版定位】
本版是工作之家 V2.0 的最终收口版。完成浏览器人工验收后，工作之家主结构进入真实使用验证阶段；非阻塞性问题进入待优化清单，不再阻塞美和跨境业务主线开发。

【本版是否需要数据库迁移 / Backend部署】
不需要。
- 不新增0061迁移。
- Cloud SQL继续保持0060_object_reactions.sql。
- Backend继续使用已部署的V1.9.36能力。
- 本版主要是前端、Header/Sidebar、Work Item Browser与工作入口收口。

【本版更新重点】
1. 工作之家Sidebar进一步收口：
   工作概览 → 今日工作 → 全部工作 → 我的关注 → 我的建议 → 我的创新 → 事业工作 → 团队工作 → 工作记录。
   等待中 / 异常处理 / 待验收不再占Sidebar章节，统一进入“全部工作”快速状态筛选。

2. Sidebar顶部新增高频“＋ 创建工作”：
   点击后直接打开美和AI并预填“我要创建/交代一项工作：”。
   当前继续沿用既有美和AI Proposal → 人工确认 → Work Item真实链路。
   本版不声称已经完成跨人员直接分配权限；组织上下级/平级工作请求留待组织权限阶段实现。

3. 全部工作统一浏览工具栏：
   搜索 → 关系 → 事业 → 成员 → 状态 → 优先级 → 时间 → 更多筛选 → 排序 → 列表 / 卡片 → 刷新。
   “今日工作”移到页面标题右侧作为明显主入口，不再伪装成筛选项。

4. 新增正式“排序▼”：
   美和AI建议优先 / 优先级高→低 / 截止时间近→远 / 最近更新 / 最近创建。
   今日工作默认美和AI建议优先；全部工作默认最近更新，便于快速找到新建/刚变化的工作。

5. Work Item Browser默认12项/页：
   超过12项显示上一页 / 下一页。
   搜索、筛选、排序、显示方式变化后回到第一页。

6. 全部工作增加成员筛选与“我布置”关系筛选。
   “我布置”当前兼容已有/未来assigned_by元数据；如果没有显式assigned_by，则仅以“我创建且负责人不是我”作为兼容识别。
   真正跨用户直接布置权限仍待组织权限正式开发。

7. 当前事业从Sidebar彻底移回Header：
   “事业之家 │ 美和跨境▼”为一个统一当前事业组件。
   左侧进入事业之家，右侧切换事业。
   业务工作台Sidebar不再重复显示“当前事业 / 美和跨境”。

8. 修复工作概览启动错误：
   ReferenceError: businessHtml is not defined。

9. 工作页面标题增加统一主题字占位“工”。
   未来正式图标体系完成后可从公共组件/配置统一替换。

10. 美和工作9问继续标记“验证中”：
    当前仅作为Work Item结构与美和AI整理框架使用；真实使用一段时间后再判断是否纳入正式美和方法论。

【Windows本地更新】
1. 确认本地仓库：
   D:\miwa\code\
2. GitHub Desktop确认main没有未提交的重要改动。
3. 将ZIP中的code内容“合并覆盖”到：
   D:\miwa\code\
   不要删除原目录后重建。
4. PowerShell执行：
   cd "D:\miwa\code\apps\systems\aione"
   node .\tests\verify-work-home-v1.9.38.mjs
5. 验证通过后GitHub Desktop Commit并Push main。
6. 等待现有前端部署完成后，浏览器Ctrl+F5。

【浏览器最终验收】
A. Header事业组件
- 显示“事业之家 │ 美和跨境▼”。
- 左侧事业之家可进入当前事业入口。
- 右侧可切换事业。
- 选品/测样等事业Sidebar顶部不再出现“当前事业 / 美和跨境”。

B. 工作之家Sidebar
- 顶部有“＋ 创建工作”。
- Sidebar不再出现等待中 / 异常处理 / 待验收。
- 团队工作、工作记录仍正常。

C. 全部工作
- 标题前显示“工”主题标识。
- 标题右侧有明显“今日工作”和“查看工作手册”。
- 主工具栏尽量保持一排：
  搜索｜关系｜事业｜成员｜状态｜优先级｜时间｜更多筛选｜排序｜列表｜卡片｜刷新。
- 更多筛选展开后保持紧凑。
- 快速状态按钮可切换全部 / 进行中 / 等待中 / 异常处理 / 待验收。

D. 排序
- 排序下拉包含5种排序。
- 选择“最近创建”可以快速找到刚创建的工作。
- 全部工作刷新后默认按最近更新浏览。
- 今日工作仍按美和AI建议优先，不因为别人被布置了新工作就强行进入当前用户的今日执行队列。

E. 分页
- 工作事项超过12项时显示分页。
- 翻页不丢失筛选与排序。
- 改筛选/排序后回到第1页。

F. 创建工作
- 点击“＋ 创建工作”打开美和AI。
- 用自然语言创建一条自己的工作，AI Proposal确认后进入Work Item。
- 创建成功后可在全部工作中通过“最近创建/最近更新”找到。
- 跨成员直接布置权限本版不做假实现；后续结合组织关系正式开发。

G. 回归
- 点赞、关注正常。
- Work Item详情可打开。
- 开始执行 → 证据 → 提交完成 → 验收闭环不回归。
- Header工作提醒不回归。
